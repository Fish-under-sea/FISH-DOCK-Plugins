# 本仓的个人环境档案（docs/agents）

这里是 FISH-DOCK-Plugins 插件仓的**按人存放的环境档案**。跨机器成立的口径在仓库根的 `AGENTS.md`；
每个作者自己那台机器的路径、工具链、凭据位置、缓存盘放在本目录的 `local/<用户名>.md`，**同样入库**。

## 为什么入库

- 换机器、重装、接手别人的活时，环境事实不用再回忆一遍。
- 别人卡在「脚本找不到」「缓存写不进」「Go 编译失败」时，可以直接对着你的档案查差异。
- 档案是文档，不是配置：**不要在这里写令牌、密码、私钥本身**，只写它们在哪台机器的哪个文件里。

## 命名与识别

| 步骤 | 做法 |
| --- | --- |
| 取用户名 | PowerShell：`$env:USERNAME` |
| 规范化 | 转小写；空格、`\`、`/`、`:` 及非 ASCII 字符替换为 `-`；连续 `-` 合并 |
| 文件名 | `<规范化用户名>.md` |
| 例 | `Fish` → `local/fish.md`；`Zhang San` → `local/zhang-san.md` |

档案第一行写回原始用户名，方便核对：

```markdown
> 机器：<原始用户名>（`$env:USERNAME`），用户目录 `<用户主目录>`。
```

## 新建流程

1. 复制 `local/_template.md` 为 `local/<你的名字>.md`。
2. 逐项填写；不适用的项写「未装」或「不适用」，**不要留空**——留空会让下一个人以为漏填。
3. 随你的一次正常提交一起入库，提交信息里注明 `docs(agents): 建立 <用户名> 的本机环境档案`。
4. 环境变了就改这份文件，别新建第二份。

## 与 `AGENTS.md` 的优先级

- **路径、工具链、凭据、缓存位置**：以本目录的个人档案为准。
- **规则、契约、发布口径**：以仓库根 `AGENTS.md` 为准。
- 个人档案里写的规则类内容一律无效，看到就应当挪回 `AGENTS.md`。

## 目录内容

| 文件 | 说明 |
| --- | --- |
| `local/_template.md` | 模板，新建时复制 |
| `local/<用户名>.md` | 各人自己的环境档案 |
