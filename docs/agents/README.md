# 本仓的个人环境档案（docs/agents）

这里是 FISH-DOCK-Plugins 插件仓的**按人存放的环境档案**。跨机器口径位于仓库根 `AGENTS.md`；每位作者各自机器的路径、工具链、凭据文件位置与缓存路径记录在 `local/<用户名>.md` 并随仓入库。

## 为什么入库

- 换机、重装或交接任务时可直接查到真实环境事实。
- 排查「脚本找不到」「缓存无权写入」「Go 编译失败」时便于对照机器差异。
- 档案仅记录文件路径与工具版本，凭据正文保存在本机凭据文件中。

## 命名与识别

| 步骤 | 做法 |
| --- | --- |
| 取用户名 | PowerShell：`$env:USERNAME` |
| 规范化 | 转小写；空格、`\`、`/`、`:` 及非 ASCII 字符替换为 `-`；连续 `-` 合并 |
| 文件名 | `<规范化用户名>.md` |
| 例 | `Fish` → `local/fish.md`；`Zhang San` → `local/zhang-san.md` |

档案第一行写回原始用户名以便核对：

```markdown
> 机器：<原始用户名>（`$env:USERNAME`），用户目录 `<用户主目录>`。
```

## 新建与维护流程

1. 复制 `local/_template.md` 为 `local/<规范化用户名>.md`。
2. 逐项填写；不适用项写「未装」或「不适用」。
3. 提交入库，提交信息使用 `docs(agents): 建立 <用户名> 的本机环境档案`（或 `更新 <用户名> 的本机环境档案`）。
4. 环境变更时原地更新这份文件。

## 与 `AGENTS.md` 的优先级

- **路径、工具链、凭据位置、缓存位置**：以本目录的个人档案为准。
- **规则、契约、发布口径**：以仓库根 `AGENTS.md` 为准；新增规则统一维护在仓库根 `AGENTS.md`。

## 目录内容

| 文件 | 说明 |
| --- | --- |
| `local/_template.md` | 模板，新建时复制 |
| `local/<用户名>.md` | 各人自己的环境档案 |
