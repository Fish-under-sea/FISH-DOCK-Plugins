# OFM 历史适配层（已退役）

此目录保存原 `plugins/ofm/` 的 5 个文件，供历史追溯，不是当前插件入口，也不是 OFM 上游完整源码。

## 状态与原因

OFM 于 2026 年 10 月 25 日暂停维护，最后公开插件版本为 2.0.1，早已不在当前商店目录中。本次将适配层移出活动插件树，避免开发暂存、发行包、npm 包与验包工具继续把它当作受维护组件。

历史暂存器依赖的 `packages/standalone/backup.mjs` 等上游结构已经变化；过去只能复用已暂存服务目录，不能据此声称从当前上游源码可重建。相关当时事实保留于[2.0.1 发行记录](../../releases/2.0.1.md)。

## 档案边界

- 文件内容与历史相对导入保留，**不在此目录直接运行或恢复暂存**；旧导入以当时的 `plugins/ofm/` 位置为前提。
- 活动构建工具不再导入此目录，不接受 `--ofm` / `--ofm-staged`，也不将 `ofm` 注册为可发行插件。
- 不下载上游服务，不复制用户账号、密钥或资料。归档不会卸载用户已有插件，也不会删除用户数据。
- 不重写旧发行说明或篡改已发布目录的摘要。若未来恢复维护，需要新的设计、上游接口核对、许可证核对与完整回归，而不是重新挂上旧入口。
