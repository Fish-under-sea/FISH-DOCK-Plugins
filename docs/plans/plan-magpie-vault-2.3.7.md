# Magpie 2.3.7 开发计划：独立知识库与 Obsidian

状态：生产程序与发行材料已完成构建，等待发布完成；线上版本仍以 `catalog/stable.json` 为准。

## 已确认范围

- 本轮固定上游 `v0.1.4262`（`30de93e9e9d5bf6a013b1773010700d8eaa707f0`），移植 Fish 完整补丁，保留 Dock 原功能。
- **新知识库归插件持久数据所有**：`credentials/magpie-runtime/data/knowledge/github-capability-vault/`，不放插件包或临时目录。
- 首次复制指定旧知识内容并逐文件校验；之后不再依赖旧源。旧 Documents 库本次不删，也不通过 junction/symlink 指回旧库。
- 原生短记忆放 `memories/`，保留 ID、scope、状态、元数据、journal、手改保护和 digest；长知识笔记保留目录，不硬塞进 2000 字短记忆。
- Magpie/MCP 与 Obsidian 共用一份文件；普通笔记检索不调用模型，遗忘短记忆不删除知识笔记。
- Obsidian 专用桌面插件随包分发：模型选择、多轮对话、检索、整理选文、保存新笔记/待确认记忆。默认不覆盖原文、不自动上传整库。
- 本机连接是独立回环端口、私有令牌与固定操作白名单。配对文件在库外；供应商密钥不进入知识库。
