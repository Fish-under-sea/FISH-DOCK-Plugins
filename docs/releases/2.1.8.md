## 二、Clash 2.1.8

### 1）节点测速不再被宿主的 15 秒掐断

**根因**（`service.mjs` + Dock 的 `plugin_rpc_timeout`）：旧实现是「并发 6 + 每个节点 5 秒」。37 个节点要跑 7 轮，最坏 30 秒以上，而宿主给一次插件 RPC 只有 **15 秒**（`DEFAULT_PLUGIN_RPC_SECS = 15`）；超时后宿主回一句没有错误码的「插件响应超时」，页面只能折叠成「未识别错误，请重试；若反复出现，请打开插件日志查看原始错误码」。`~/.fish-dock/host/plugin-failures.log` 里那一串 `插件响应超时 … fish.clash` 就是它。同一个 3.5 秒的控制器超时还套在所有请求上，而测速本身要求内核给 5 秒——单节点也必然先被客户端掐断。

**本版**：

- 测速自己带预算：并发 8、单节点 2.5 秒、整段 9 秒封顶；来不及测的节点如实记成 `untested` 计数，不再把整次调用拖到宿主超时；
- 请求层支持按调用给超时（默认仍是 3.5 秒）：测速 2.5+0.5 秒、站点探测 6 秒、热重载 4.5 秒；
- 页面把宿主那两句没有错误码的话折叠成能看懂的中文：**「这次操作超过了宿主的 15 秒上限（插件仍在运行）：请稍后重试；反复出现请减少启用的订阅节点数」**，不再落到「未识别错误」。

### 2）换订阅启用：热重载失败时插件自己重启内核

旧行为是「热重载失败 → 回滚 → 让用户自己去重启内核」。本版改成：

1. 先热重载（`PUT /configs?force=true`），成功就是无缝切换；
2. 热重载失败立即**按新启用集重启一次内核**（停旧 → 起新 → 校验 `/version` → 写回运行态），用户不用动手；
3. 两次都失败才回滚启用集，并报 `SUBSCRIPTION_SWITCH_FAILED`（文案同步改成「已回滚到原启用集；请刷新后重试，反复失败请打开插件日志查看原始错误码」）。

重启不经过 `start()`：那会走同一条操作队列，与本次调用互等；这里直接按 runtime 起一次，并把运行态落盘，保证插件下次重载还能 attach。

### 3）关掉 geo 自动更新

运行时配置里的 `geo-auto-update: true` 会让内核在**启动或热重载那一刻**自己去 GitHub 拉 `geosite.dat` / `geoip.dat`。网络不通时 mihomo 直接 `Parse config error` 退出——本地实测：GeoSite 从随包文件读到了，GeoIP 找不到去下载，20 秒后 fatal 退出。

geo 文件本来就随插件发布，启动时 `ensureGeoData` 会把它们落到内核目录，这一项没有保留的必要，本版置为 `false`（内核在文件真的缺失时仍会自己尝试下载，那是它自己的兜底）。

### 4）文案与版本位

`SUBSCRIPTION_SWITCH_FAILED` 的新文案在 `shared/errors.mjs` 与 `plugins/clash/page.js` 两处逐字一致（`page.test.mjs` 会逐码比对）；「请更新插件到 2.1.5」两处提示改成 2.1.8。

## 三、Magpie 2.1.8

### 1）追上游：`v0.1.2732` → `v0.1.2799`

- 补丁 `magpie-v0.1.2799+fish.12.patch`（对 pristine `v0.1.2799` `git apply -3`）：**只剩一处冲突**——`internal/gui/core_budget_test.go` 的预算常量。按上游注释的规矩取实测值：核心脚本 1,534,429 字节（上游 cap 1,533,802，只差 627 字节，全是我们补丁加进核心脚本的那几百字节），写明为什么上调，不留余量。
- 上一版的两件事都在：NearToken 让出供应商（#22）、中转站探针的图钉图标。

### 2）NearToken 契约补齐：`neartoken:state` 多回 `groupList` 与 `tokenName`

页面要画「分组墙」，宿主多给一份分组数据：

```json
{ "groupList": [ { "name": "[低价] Grok", "ratio": 0.1, "models": 12, "ref": "#37" } ] }
```

- `name`：站点 `/api/pricing` 的 `enable_groups` 原文，含 emoji 与备注，照抄不翻译；
- `ratio`：`group_ratio[name]`，站点没给就省略（页面据此不画倍率）；
- `models`：这一组下能聊的模型数（`-c` 变体、生图/向量/语音那些仍然不算）；
- `ref`：`group_refs[name]`，可选；
- 顺序按分组在站点目录里首次出现的顺序，不按倍率或数量重排；
- 没读过目录时是**空数组**，不是 `null`——页面直接遍历。

页面把这一份渲染成可点的分组墙；点一下写进 plugin options 的 `disabledGroups`，插件自己的 `provider.models` 按它过滤，**开关是原生生效的，这一半不需要宿主改动**。

`tokenName`：自己连的时候用站点回的名字；之后从插件凭据里读（`keepWithPlugin` 现在把 `tokenName` 一起存进插件 auth），页面「令牌名」那一栏不再是空的。

## 四、验证

- **Clash**：`service.test.mjs` 41/41，`page.test.mjs` + `runtime.test.mjs` 82/82（新增两条：热重载失败→重启生效、两次都失败→回滚；夹具加 `refuseStart`）。
- **Clash 的本地复现**（`.work/clash-lab`，真实 mihomo 1.19.15）：`PUT /configs?force=true` 用绝对路径返回 204 且内核存活；相对路径返回 400 `path is not a absolute path`；`geo-auto-update: true` 且缺 geo 文件时内核会去下载并 fatal 退出——三条都在本机跑到过。
- **Magpie**：`internal/neartoken` 单测全绿（含新增的 groupList / 空数组 / tokenName 三条）；`internal/plugin` / `internal/provider` 的既有失败是本机环境（符号链接权限、命名管道、keyring），与本次改动无关。
- 补丁对 pristine `v0.1.2799` `git apply --check` 干净；两个包 `verify-release` 通过；发行后核对下载地址与字节数。
