# 2.4.3 · 侧栏与外观页的秩序、玻璃补全、壁纸自动压缩

Magpie `v0.1.4262+fish.40`，Clash 2.4.3。飞书保持 2.2.0。

## Magpie

### 侧栏变长时不再顶开整页

资源库展开后子项多出十余条，侧栏本身没有内部滚动，整列就超过窗口高度，把下面的分组与页面一起顶下去。

`#nav` 现在 `overflow-y:auto` + `min-height:0`，长菜单在侧栏内部滚动；滚动条是 6px 半透明细条，不占视觉。

### 外观页：底图遮挡并入液态玻璃卡，两卡换序

- 新增「底图遮挡」滑块（`fishGlassVeil`）：**0 = 自动**，跟随页面自身不透明度计算（内容区越透，遮罩越厚，字才读得清）；1–95 = 固定值。
- 外观页顺序改为「液态玻璃」在上、「字体颜色」在下。

### 字体颜色实时生效

取色器以前每拖一像素就发一次保存请求，画面要等服务端回包才变，表现为「点很久才生效」。

现在拖动时**直接写 `--fg/--fg-2/--muted/--faint`**，画面立刻跟上；落盘改为最后一次改动后 250ms 防抖。

### 记忆 Agent 面板汉化

`Reads conversations` / `Tidies memory` / `Dreams` / `Runs as …` / `Presets: …` / `Add an agent` / `Bring the presets back` 等 11 条文案此前只有代码没有词条，中文界面里整块是英文，现已补齐。

### 玻璃补全（本轮系统排查）

方法：把 `app.css` 里所有写死 `background: var(--card|--layer|--bg)` 的选择器列出来，逐个判断归属。缺少的玻璃分三类：

| 类型 | 例子 | 处理 |
| --- | --- | --- |
| 与 `.list` 同级的「面」 | 额度表 `.qt-wrap`、`.subscription-card`、`.kpi`、`.chart`、`.ag-install-row` | 接 `--fish-glass-content-fill` |
| **套在 `.list` 里的块** | `.subscription-acct`、`.row.stat .us-more`、`.qt .qt-sub` | 改 45% 半透——父级已经在当玻璃，子块再盖实底就永远透不下来（这是「看着缺玻璃」的主因） |
| 吸顶条 / 菜单 | 设置页 `.set-head::before`（自刷 92% 底）、`.row-menu`、`.us-more.open` | 分别归内容区 / 浮层区，带 blur |

## Clash

| 项 | 修法 |
| --- | --- |

| 壁纸传不上去 | 见下 |

### 壁纸上传：在页面里先压到桥的额度内

宿主的页桥对单条 `fish:call` 消息有 512 KiB 上限，且**超限静默丢弃**（`extension-page.js` 的 `accepts()` 返回 false 就没了），页面只会看到 20 秒超时。图片走 base64 再套 JSON 约放大 1.37 倍，所以真正能过的原图只有约 350 KB。

现在选图后先在页面里解码 → canvas 重采样（上限 2560px）→ 逐级降质（0.88→0.56）→ 再降尺寸（8 轮），直到 data URL ≤ 360 KiB 才发送。**用户选多大的图都能成**，不再依赖宿主放宽限制。

宿主侧仍建议：把 512 KiB 提到 ≥1.2 MiB，并让超限**报错**而不是静默丢弃。
