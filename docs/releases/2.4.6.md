# FISH DOCK Plugins 2.4.6 发行说明

**Magpie `2.4.6`**（上游基线追平至 `yetone/magpie@v0.1.4344`，累计补丁 `v0.1.4344+fish.46` / Windows FileVersion `0.1.4344.46`，要求宿主 FISH Dock ≥ 2.3.4）、**Clash `2.4.6`**（要求宿主 FISH Dock ≥ 2.0.0），**飞书维持 `2.2.0`** 不动。

## Magpie `2.4.6`（`v0.1.4344+fish.46`）

### 1. 上游基线追平至 `v0.1.4344`

- 上游基线从 `v0.1.4262` 前移至 `v0.1.4344`（tag object SHA `00b2c11a6b481bc1c2a909dfa9f5396f618fdd28`），导出累计单一补丁 `plugins/magpie/patches/magpie-v0.1.4344+fish.46.patch`（253 个文件 / 442 个 hunk），干净源码包 `git apply` 零冲突通过，并通过 `check-assets-refs.mjs` 与 `check-upstream-freshness.ps1 -RequireLatest` 检查。
- 更新 `internal/gui/core_budget_test.go` 资产脚本预算阈值（`appScriptBudget = 1_090_728`、`coreScriptBudget = 1_277_192`），并通过全部资产脚本 `node --check`。

### 2. Obsidian 记忆 Agent UX 收敛、全汉化与提示词重写

- **单一 Agent 收敛与卡片精简**（`internal/gui/assets/plugins/library/client.js`、`i18n.js`、`library.css`）：
  - 在 Obsidian 工作区模式下，移除「从对话中学习」与「每晚整理」行内多余的 Agent 下拉选择器，以及底部重复记忆 Agent 选择行，统一收敛至 `Obsidian 记忆 Agent`；非 Obsidian 环境仍保留原有逐行下拉兜底。
  - 移除 `共享知识库`（`.lib-vaultcard`）卡片下方冗余的搜索输入框，仅保留「在 Obsidian 打开」入口按钮，并保持 `12px` 卡片间距。
- **常驻运行行与交互修复**：
  - 将 `.lib-memrun` 设为常驻行，补全状态、阶段与工具动作中文文案，直接提供「立即整理」按钮与启用/停用开关（对接 `POST /api/memory/agents/obsidian/enabled`）。
  - 修复 `.proto-menu` 下拉开关点击行为：再次点击 `menuButton` 可直接关闭已展开菜单。
- **提示词与沙箱边界重写**（`internal/agent/obsidian_memory.go`、`internal/memagent/sandbox.go`）：
  - 重写记忆 Agent 系统提示词与策略规则：`Sandbox.Write` 允许写入 `dreams/`，移除对 `memories/` 的直接文件写入（`memories/` 统一通过 `magpie-memory` MCP 读写），同步给下游 Obsidian **潮汐插件** 的记忆契约以 `dreams/` 目录与 MCP 读写为准。
- **Obsidian 插件打包与部署修复**（`plugins/magpie/knowledge-vault.mjs`、`obsidian-plugin/main.js`、`obsidian-plugin/view.test.cjs`、`tools/stage-development.mjs`、`tools/verify-release.mjs`）：
  - 将 `rules.js` 纳入 `obsidianResources` 白名单，修复发版包漏带 `rules.js` 导致部署缺失的问题；为 `main.js` 增加 `loadAgents()` 并发序号防重入保护并加固 `view.test.cjs` 状态等待。

### 3. 液态玻璃 `0%` 全透明与 Agents 页重叠修复

- 修复选取深色玻璃颜色（如 `#000000`）时，即使将侧边栏 / 顶栏滑块调至 `0%` 不透明度仍因 `--lg-glass-wash` 残余底色而无法完全隐藏的问题；`fishGlassHeader`、`fishGlassBar`、`fishGlassVeil` 在 `prefsKeep` 与 `internal/settingsapi/settingsapi.go` 中正确保留。
- 修复 `app.js` 中当 `fill === 0` 且 `blur > 0` 时仍绘制侧边栏右边框的问题，并在 `fish-glass.css` 中在 `0%` 下彻底清除 `.sidebar .side-foot` 分隔线与移动端 `#nav` 边框底色，基于 `v0.1.4344` 重新生成 `162` 条表面规则。
- **修复 Agents 页 `Obsidian 记忆 Agent` 详情行重叠**（`internal/gui/assets/app.css`）：`.ag-obs-detail` 原先采用 `flex-direction: column`，子行 `pairLine` 同时携带 `.ag-st`（`flex: 0 0 100%`）导致竖向被撑满 100% 高度，将「最近运行」挤出容器边界并压在「模型列表」行上；改为 `display: grid` 并重置 `.ag-obs-detail > .ag-st { flex: none; width: auto; }` 后彻底消除重叠。

## Clash `2.4.6`
