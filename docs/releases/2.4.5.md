# 2.4.5 · Clash 液态玻璃与 TUN 修复、Magpie 液态玻璃解耦与 Obsidian 记忆 Agent（fish.45）

Clash 升级到 **2.4.5**，Magpie 升级到 **2.4.5**（原生标识 `v0.1.4262+fish.45`，Windows 文件版本 `0.1.4262.45`）；飞书保持 **2.2.0**。要求宿主 **FISH Dock ≥ 2.3.4**（Magpie）/ **≥ 2.0.0**（Clash）。

## Magpie（2.4.5 · `v0.1.4262+fish.45`）

- **Obsidian 记忆功能纳入正式 Agent 与统一工作区管理（`fish.45`）**：将 Obsidian 记忆功能实现为正式 Agent，工作区位于知识库 `.obsidian` 目录下，由 Magpie 统一发现与管理，提示词、技能与权限与常规 Agent 保持一致，覆盖 [`plugins/magpie/obsidian-bridge.mjs`](../../plugins/magpie/obsidian-bridge.mjs)、[`plugins/magpie/obsidian-plugin/main.js`](../../plugins/magpie/obsidian-plugin/main.js) 与累计补丁 [`plugins/magpie/patches/magpie-v0.1.4262+fish.45.patch`](../../plugins/magpie/patches/magpie-v0.1.4262+fish.45.patch)。
- **液态玻璃全表面覆盖与玻璃颜色解耦（`fish.42`～`fish.44`）**：
  - 补全用量四页签卡片、浮层提示、展开行与控件的液态玻璃与 360° 菲涅尔描边。
  - 修复壁纸模式下侧边栏 `#lookCSS` 优先级压制，支持 `0%` / `0px` 真全透与零滤镜损耗。
  - 新增独立玻璃颜色（`fishGlassColor`）并迁入液态玻璃面板，将强调色迁回字体颜色面板，二者各自生效互不覆盖。
  - 更新 `plugins/magpie/tools/glass-surfaces.mjs`，排除非正文选择器并以中性玻璃变量重生成 159 条表面规则。

## Clash（2.4.5）

- **TUN 服务状态恢复与切换逻辑修复**：
  - `plugins/clash/service/tun-service.cs` 增加 `job.ini` 的 `FileSystemWatcher`、BOM 剥离及 `hostGone` 租约恢复，并重编随包 `tun-service.exe`。
  - `plugins/clash/tun.mjs` 在安装时写入无 BOM UTF-8 且等待卸载删除与启动就绪；启停改为基于历史日志偏移判断，避免误判秒过。
  - `plugins/clash/service.mjs` 暴露代理组 `type`，区分不可手动选择组与 `400` / `404`；`tunSwitch` 支持停机时同步落盘，以及运行中启动失败时回滚 `tun.enable` 并暴露错误。
- **液态玻璃视觉对齐与下拉/配色控件修复**：
  - `plugins/clash/page.css` 补齐 360° Fresnel 高光边与深浅主题双色玻璃 token、`.listbox` 细滚动条与平直过滤框、`.fc-input` 紧凑色块、`.tun-box legend` 及 `blur = 0` 零滤镜开关。
  - `plugins/clash/page.js` 优先选择 `Selector` 组并锁定自动组节点选择，防止订阅卡内按钮点击冒泡切换，收紧下拉上翻阈值并同步 `--g-*-filter`。
