# 2.5.1 发行说明

**Clash** 升级到 **2.5.1**（修复 `mihomo v1.19+` provider 节点测速超时、完善环境变量代理随 TUN 联动与自动清理、重构概览「网络设置 / 代理模式」卡片排版，要求 FISH Dock ≥ 2.0.0），**Magpie** 保持 `2.5.0`（`v0.1.4650+fish.50`，要求 FISH Dock ≥ 2.3.4），**飞书**保持 `2.2.0` 不变。

## 本版更新（Clash 2.5.1）

- **修复延迟测试（网站测试 / 节点测速）在 `mihomo v1.19.34` 下全部超时的问题**（`plugins/clash/service.mjs`）：
  - 在 `mihomo v1.19+` 中，由 `proxy-providers` 挂载的订阅节点仅位于 `/providers/proxies`，直接调用 `/proxies/<name>/delay` 会返回 HTTP `404`（被折算为 `NODE_STALE` / 超时）。
  - 新增 `fetchProxiesCatalog()` 与 `testProxyDelay()`，在 `view()`、`siteTest()` 与 `nodeTest()` 中合并 `/providers/proxies` 目录并补全 `resolveLeaf()` 与节点协议/延迟；provider 节点统一路由至 `/providers/proxies/<provider>/<name>/healthcheck`（保留对 `/proxies` 条目的 `404` 回退）。
- **完善环境变量代理（`envProxy`）随 TUN 联动与自动清理**（`plugins/clash/service.mjs`、`plugins/clash/runtime.mjs`）：
  - 未显式配置 `envProxy` 时默认跟随 `tun.enable`（关闭 TUN 时默认关闭 `envProxy`）；
  - `tunSwitch`（在线/离线）、`save` 更改 `tun.enable` 以及 `uninstallTunService` 同步联动开启或关闭并清理用户环境变量（切换失败完整回滚）；
  - `stopKernel()`、`abandonStart()` 与意外停服场景（`view()` 的 `serviceDead`、已退出 PID 的 `attachRunning()`）并行还原 `proxy` 与 `envProxy`，并将 `powershellEnv` 写入改为原生 .NET `[System.Environment]::SetEnvironmentVariable(..., 'User')`，消除 `Add-Type` C# 编译耗时，避免关闭窗口期内残留 `HTTP_PROXY` / `HTTPS_PROXY`。
- **重构概览「网络设置」与「代理模式」卡片排版**（`plugins/clash/page.js`、`plugins/clash/page.css`）：
  - **网络设置**：移除三行开关下的绿色 `.small.muted` 小字与底部 `.status-line`（完整说明收入按钮 `title`），通过 `.switch-list`（`flex: 1 1 0`）均分卡片高度，使单行白色标签与开关按钮严格垂直居中对齐并与右侧卡片等高匹配；
  - **代理模式**：在分段模式切换下方新增内嵌网络状态子卡（`.route-card`，复用 `--lg-inner-bg` / `--lg-inner-line`，不嵌套 `backdrop-filter`），清晰展示 **流量接管**、**环境变量**、**分流方式** 与 **当前出口**。
