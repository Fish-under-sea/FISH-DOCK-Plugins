**Magpie `2.4.7`**（上游基线 `yetone/magpie@v0.1.4344`，累计补丁 `v0.1.4344+fish.47` / Windows FileVersion `0.1.4344.47`，要求宿主 FISH Dock ≥ 2.3.4）、**Clash `2.4.7`**（要求宿主 FISH Dock ≥ 2.0.0），**飞书维持 `2.2.0`** 不动。

## Magpie `2.4.7`（`v0.1.4344+fish.47`）

### 1. 外圈与嵌套液态玻璃修复

- 在 `internal/gui/assets/fish-glass.css` 中补全外圈玻璃容器覆盖清单（包括 `.rt` 路由舞台/日志卡、`.lib-card:not(.lib-install)`、`.lib-empty`、`.mk-card`、`.msk-card` / `.msk-req` / `.msk-blocked` / `.msk-content` / `.msk-how` / `.msk-demo`、`.pr-stage` / `.pr-picks` / `.pr-none` / `.pr-list`、`.pu-tot` / `.pu-heat`、`.rt-gimport`），完整启用 `position: relative`、`backdrop-filter`、凸面釉光 `::before`、360° conic 绕边高光 `::after` 与降透回退，修复 `0%` 填充下外框全透明的问题。

### 2. 黑框、黑环与交互态统一

### 3. 字体颜色命中与 Obsidian 紫色图标

- 在 `internal/gui/appearance.go`、`assets/app.js`（`applyFontColors`）与 `assets/appearance.js` 补全 `--ctl-fg` 输出与 `html:not(.omarchy):root` 暗色主题权重覆写，确保标签页、分段按钮与操作文本准确跟随自定义字体颜色；更新 `core_budget_test.go` 核心脚本预算（`appScriptBudget = 1_091_412`、`coreScriptBudget = 1_277_876`）。
- 在 `internal/gui/assets/app.css` 全局添加 `input::placeholder, textarea::placeholder { color: var(--faint); opacity: 1; }`，使插件页手动输入框等占位文字正确命中字体配色。
- 新增多切面紫色晶石 `internal/gui/assets/icons/obsidian-color.svg`，并在 `icon()` 中将 `obsidian` 指向彩色版本（保持后端 `Icon: "obsidian"` 不变）。

## Clash `2.4.7`

### 1. TUN 稳定性、流程锁与网速优化

- **防止 TUN 服务自删与读写竞态断连**（`plugins/clash/service/tun-service.cs` / `tun-service.exe`、`tun.mjs`、`service.mjs`）：移除自删除与配置清理路径；`ReadJob()` / `HostIsGone()` 改用共享读与瞬态重试，`HostIsGone()` 增加 3 次宽限；`writeJob()` 支持临时文件原子写入并在受限 ACL 下回退单次写；接管真实运行服务后自动续签宿主 PID 租约。
- **完善并发流程锁与无内核约束**（`service.mjs`、`runtime.mjs`、`page.js`）：禁止内核未运行或 TUN 服务未安装时独立启用 TUN（返回 `KERNEL_NOT_RUNNING`）；`tunSwitch`、`start`、`stop`、`editable`、`reload`、`proxy` 全链路补齐 `tunBusy`（`KERNEL_SWITCHING`）互锁，失败回滚并回收半启动 TUN 状态防止断网；前端 `page.js` 在未运行或切换中禁用相应操作开关。
- **修复 TUN 模式下网速异常变慢**（`runtime.mjs`）：默认启用 `find-process-mode: 'off'` 与 `keep-alive-idle` / `keep-alive-interval`，开启 TUN 时补全 `ipv6: false`、`tun.mtu: 1500`、`strict-route: true`、`dns-hijack`、`route-exclude-address`、`dns.default-nameserver` / `proxy-server-nameserver` / `fake-ip-filter` 与 `sniffer`，并在启动 TUN 前清理指向自身混合端口的遗留系统代理。

### 2. 面板 UI 与交互修复

- **输入框占位文字着色**（`plugins/clash/page.css`）：`input::placeholder, textarea::placeholder` 绑定 `var(--dock-muted)`，随「次要文字」配色生效。
- **节点组弹窗优先向下展开**（`plugins/clash/page.js` `openListbox`）：下方视口空间不足时先向下滚动 `#pane` 并重测触发器坐标，避免误向上弹出遮挡订阅卡片。
- **内核设置长路径换行与头部间距修正**（`plugins/clash/page.css`）：`.tun-box` 增加 `min-inline-size: 0`，`.svc-log` 与 `.tun-service p` 允许折行与内部滚动；`.pane.settings` 恢复顶部与左侧 `16px` 内边距，防止「内核设置 / 外观」标题被顶部栏遮挡。
