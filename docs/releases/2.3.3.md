# 插件 2.3.3（Magpie + Clash）

> 2.3.2 的紧急补丁：只改 Magpie 管理页的两处界面问题，无行为变更。
> Magpie 的 `magpie.exe` 重编到补丁 **`v0.1.3240 + fish.29`**（2.3.2 是 fish.28）。
> 校准：FISH Dock ≥ 2.0.0、宿主 API 1、Windows x64。

## 设置 › 图像：删掉重复的「生图超时」行

2.3.2 把生图 / 视频 / 语音 / 向量的超时做成了模型行右侧的胶囊（`N 分钟 ▾`），但上游原生的「Image generation timeout」整行没有删——页面上于是有两个入口：一个是中文标题配 5/10/15/30/60 的段选，另一个是胶囊。

本版删掉整行，生图超时只留胶囊，与另外三行一致。上游为那一行写的浏览器用例 `image-timeout-setting.test.cjs` 一并移除（该行已不存在）。

## 「素材 MCP 服务器」补上中文

「Materials MCP server」此前只有英文键，中文界面里直接露英文。本版补：

- zh：**素材 MCP 服务器**
- zh-TW：素材 MCP 伺服器
- ja：素材 MCP サーバー
- de：Material-MCP-Server

下方说明文案（`generate_image` / `generate_video` / `generate_audio` / `generation_result` 四个工具、图片与视频保留一小时的 URL、跨机访问的 Bearer 密钥）也一并翻译。
