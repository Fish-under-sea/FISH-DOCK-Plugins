# 2.4.4 · 外观页签图标、遮罩真正生效、玻璃覆盖生成、宿主页桥新上限

Magpie `v0.1.4262+fish.41`，Clash 2.4.4。飞书保持 2.2.0。

## Magpie

### 「外观」页签终于有图标了

`navicons.js` 里设置页每个页签都有自己的笔画图标，唯独漏了 `appearance`。补一滴「液态玻璃」的水滴，与其它页签同一套 16×16 线条风格。

### 底图遮挡为什么之前完全没用

遮罩写在 `/api/appearance/css` 返回的样式表里，而页面只在**强调色或壁纸变化**时才重新拉这张表（`applyPrefs` 里的 `look` 比较）。改玻璃透明度或拖遮挡滑块，key 不变 → 样式表不重画 → 遮罩永远是旧的。上一版做的「遮罩随内容区自适应」因此也从未真正生效。

两处一起修：

- 遮罩改成 CSS 变量 `--wall-veil`，由服务端算出初值（`veilFor`：用户值优先，其次玻璃随内容区，最后 84%）；
- 玻璃与遮挡滑块松手保存后主动调用 `lookPaint()` 重画外观表，不再依赖 key 变化。

### 回滚了上一版改坏的侧栏布局

2.4.3 给 `#nav` 加的内滚（`flex: 1 1 auto; overflow-y: auto`）是多余的第二层滚动容器——侧栏本来就有 `.side-scroll` 负责这件事。结果页脚与列表的排布被挤乱。整段撤回，侧栏恢复原样。

### 玻璃覆盖改为「从 app.css 生成」，不再手写清单

上一版手选的选择器漏项严重（用户：还是很没玻璃）。现在由 `plugins/magpie/tools/glass-surfaces.mjs` 扫描上游 `app.css`，把所有「用实色令牌铺底」的规则找出来，逐条挂到玻璃变量上：

| 令牌 | 命中 |
| --- | --- |
| `--card` | 82 条 |
| `--card-2` | 10 条 |

生成段落在 `fish-glass.css` 的 `gen:glass-surfaces` 标记之间，**只改 `background-color`，不碰任何布局属性**；对话正文、编辑器写作区、表单控件保持实底。要复核或重生成：

```
node plugins/magpie/tools/glass-surfaces.mjs <上游源码根>        # 只看命中面
node plugins/magpie/tools/glass-surfaces.mjs <上游源码根> --write # 落盘
```

### 页签下面那道「意义不明的底部」

设置的页头用 `::before` 刷了一层 92% 不透明的 `--bg`，并且上下各外扩 6px。壁纸与玻璃都开着时，页签下面就多出一条与四周对不上的深色唇边。现在这层底跟随页面自己的遮罩（`var(--wall-veil)`），模糊与吸顶行为不变；库与插件页的页头直接透明。

### 字体颜色：「清空」改成「重置」

- 文案改为「重置」，只在设过颜色时出现（跟随主题时不占位）；
- 点击立刻撤掉页面上的内联变量，不等服务器回包；
- 面板仍是四档（正文 / 次要 / 弱化 / 极弱），深色可单独设置。

## Clash

### 适配宿主页桥的新上限（宿主 PR #93）

宿主把单帧上限从 512 KiB 提到 **2 MiB**，并且**不再静默丢弃**超限消息，而是立刻回传带错误码的 `fish:result`。Clash 侧随之调整：

- 壁纸自动压缩的预算从 360 KiB 抬到 **1.5 MiB**（data URL 长度；base64 约放大 1.37 倍），起步分辨率 2560 → **3840px**，质量档从 0.56–0.88 抬到 0.56–0.92：同一张图现在画质更高，仍然「选多大的图都能成」；
- 新增四个错误码文案，页面按码显示：`PAYLOAD_TOO_LARGE`、`INVALID_METHOD`、`TOO_MANY_REQUESTS`、`INVALID_PAYLOAD`。旧的 20 秒超时「假死」不会再出现。

### 其他

外观页壁纸说明不再写死「上限 2 MB」，改为说明会自动压缩。

## 升级

- **Magpie**：`magpie.exe` 以新运行副本落盘；外观设置保留。已有壁纸的遮罩会立刻按当前玻璃设置重算——之前如果觉得「遮挡没反应」，这一版才是真的在动。
