# Magpie 插件 1.2.4

修 issue #9 报的两条：签到按钮点了没反应、厂商分组一进来全展开。

## 修复

- **「立即签到」永远失败（`读取签到状态失败: 缺少厂商 id`）**：页面顶部的按钮不带厂商（它的语义就是“每个都签一次”），而宿主的 `checkin:run` 以前把空的 `provider` 判成「缺少厂商 id」，于是这颗按钮点下去只有一行报错，一次签到都没跑成。现在 `provider` 省略（或为空、纯空白）就是签全部：走 `provider.CheckInPlugins(ctx)` 的 variadic 语义，与设置页「每日自动签到」同一套。带了 `provider` 仍然只签那一家。
- **「刷新今日积分」其实在重复签到**：`checkin:run` 与 `checkin:refresh` 以前共用一个分支，刷新也去签到了 —— 于是额度面板不重读、数字不更新。现在 `checkin:refresh` 单独走 `/api/usage/quotas/refresh` 那条逻辑（`provider.RefreshUsage`，30 秒超时，不带 `provider` 就把页面上的厂商每家重读一遍），返回整页状态供页面重画。

## 页面

- `page-checkin` 0.2.4：**厂商分组默认收起**，一进来先看「今日已签到 x / y + 积分」，点标题才展开账号列表；包选项写成 `collapsed: true`，老偏好 `collapsed: false` 仍可让全部分组展开。
