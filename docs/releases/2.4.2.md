# 2.4.2 · 液态玻璃的可读性、Clash 外观页修正

Magpie `v0.1.4262+fish.39`，Clash 2.4.2。飞书保持 2.2.0。

## Magpie：玻璃开到低不透明时，内容区“消失”

**现象**：把「主界面」的不透明度拖低，内容区越来越空，最后只剩壁纸——侧栏还在，正文却像没了。

**根因**（`internal/gui/appearance.go`）：玻璃开着时壁纸遮罩被写死成 45%，而主界面的 `fill` 能拖到 0。此时 `.list`/`.card` 全透、页面自身没有底色，文字直接落在壁纸上，对比度崩掉。

**修复**：遮罩不再是一个常量，跟着内容区的 `fill` 走——

```
veil = 84 - 39 × (contentFill / 100)
```

| 内容区 fill | 遮罩 | 观感 |
| --- | --- | --- |
| 0% | 84% | 卡片全透，遮罩负责可读 |
| 76% | 55% | 玻璃透出来，字仍稳 |
| 100% | 45% | 卡片自己托底，壁纸只在边距露出 |
| 所有区域实底（玻璃关） | 84% | 与 2.3.x 一致 |

新增/改写测试断言这三档，并覆盖「玻璃关闭回到 84%」。

## Clash：外观页与面板细节

| 项 | 修法 |
| --- | --- |
| 「保存内核配置」条是纯黑实底 | 改用与卡片同一套玻璃底色与模糊变量，不再是死色块 |
| 示例卡片（看着没用） | 删除，连同它的死样式 |
| 滚动条常驻 | 默认隐藏，悬停/聚焦时出现 8px 细条 |
| 下拉列表跑到触发框上方、盖住页签 | 原来用 `scrollHeight` 估高（空列表回落 320），比真实高度大得多。改为先画再量真实高度，按上下可用空间选边，并夹住水平越界 |
| 外观页左侧多出空隙 | 与「概览」统一外边距（`.pane.settings` 补 `padding:0 4px 4px 0`，`.look-grid` 上边距收到 8px） |
| 无字体颜色调节 | 新增「字体颜色」卡：正文 / 次要两档，色块 + 十六进制 + 清除；留空即跟随 Dock 主题 |

## 文档

新增 [docs/developers/liquid-glass-hooks.md](../developers/liquid-glass-hooks.md)：插件页如何接液态玻璃——`magpie.glass()`、`magpie.onGlass(fn)`、`--magpie-glass-<region>-fill/-blur`、`data-magpie-glass`，含最小实现与三种降级（无 `backdrop-filter`、减弱透明、高对比度）。其他插件照此接入即可跟主界面一致。
