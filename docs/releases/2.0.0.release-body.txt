四个插件 2.0.0
================

飞书通知、Clash 代理、Magpie 网关、OFM 本地模型一起升到 2.0.0，配套 FISH Dock 2.0.0 及以上。
这一版改的是身份与自启动钩子，业务功能沿用各自上一次发布的实现（Clash 1.3.1、Magpie 1.2.4、OFM 1.0.2、飞书 1.0.2）。

安装要求（breaking）
---------------------

- FISH Dock 必须 >= 2.0.0。2.0.0 的插件清单新增 behaviors 字段；1.2.3 及更早的宿主按
  deny_unknown_fields 解析清单，会以「plugin.json 格式无效或含未知字段」直接拒装。
  旧宿主请先把 Dock 升到 2.0.0。
- 官方商店目录同步换成 authors 数组 + note；1.2.3 的目录解析器读不了新结构
  （整份目录解析失败、插件列表全空），同样通过升 Dock 解决。
- 包内版本一律三段纯数字 2.0.0（宿主 plugin_manifest::version() 拒绝任何预发布后缀）。

身份
----

- 作者改为数组：
  Clash 代理    Elysia395、FISH
  Magpie 网关   FISH、Jassdingk
  OFM 本地模型  FISH
  飞书通知      WTStarMark、FISH
- 维护者字段整体去掉：目录条目与前端都不再有 maintainer，只有 authors 数组。
- OFM 带状态说明：note 为「此插件于 10 月 25 日暂停维护」，在插件卡上单独一行显示。
  暂停维护只影响展示，不改行为，也不下架；需要模型网关请迁移到 Magpie。

自启动钩子
----------

清单里新增 behaviors.autostart：
- true（Clash、Magpie、OFM）：插件卡上是「随 Dock 启动 / 已关闭」两态胶囊；
- false（飞书）：同一位置显示灰色小字「无需自启动」，不隐藏、不占按钮语义。

宿主只在「随 Dock 启动」这一次传 FISH_PLUGIN_AUTOSTART=1；安装、点启用、回滚、手动启动
都不传 1。三个有本机服务的插件在 activate() 末尾按这个语义拉起服务，未配置或已在运行时
保持原样。服务页的复选框也换成了同规格胶囊，放在「启动服务」左侧，开关状态与插件卡写的
是注册表里同一个 autostart。

校验方式
--------

1. 下载四个 .fish-plugin 与同版 SHA256SUMS.txt，在下载目录执行：
     Get-FileHash *.fish-plugin -Algorithm SHA256
   或（Git Bash / WSL）：
     sha256sum -c SHA256SUMS.txt
2. 本地复核发行物（需要本仓源码与运行时）：
     node tools/verify-release.mjs --dist <本版 dist 目录> --npm <本版 npm 输出目录>
   verify-release 会逐资源核对归档、页面依赖引用、清单摘要，并确认 npm 副本与插件归档
   字节一致；本版四个包全部通过（包内文件数 18 / 26 / 52 / 123）。
3. 官方商店目录 catalog/stable.json 里的 sha256 / bytes 与上表同源，宿主安装前会再核对一次。
