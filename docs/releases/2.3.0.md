# 插件 2.3.0（Clash + Magpie 同版）

> 两个插件同时到 **2.3.0**；Magpie 的 `magpie.exe` 仍是补丁 `v0.1.3140 + fish.24`（本版没有重编 exe）。
> 校准：FISH Dock ≥ 2.0.0、宿主 API 1、Windows x64。

## Magpie：两个内置件改按 npm 包登记

2.2.9 的内置件是「同步目录副本 + 绝对路径」登记，那条 spec 不在 magpie 自己的更新循环里：目录副本停在发版那天的版本，上游（`@fish-under-sea/magpie-checkin-relay-probe` / `@fish-under-sea/magpie-purge`）发了修复用户也拿不到。

本版改成与 `@magpie-community` 那批预装供应商插件同一条路——只把 **npm spec** 写进 magpie 的 `plugins.json`：

```
"@fish-under-sea/magpie-checkin-relay-probe@latest"
"@fish-under-sea/magpie-purge@latest"
```

- 首装与后续更新都由 magpie 自己的更新循环按 spec 完成；
- `magpie.fish-plugin` 不再带 `bundled-plugins/` 副本（包从 36.8 MB 降到 36.3 MB）；
- **迁移**：2.2.9 的目录副本条目换成 npm spec（`options` / `off` 保留）；用户自己钉的版本原样保留；2.2.8 及更早的 `page-checkin` / `page-relay-probe` 仍整条删除；
- 代价：首次安装要联网一次。

## Clash：无功能改动

版本位跟随统一到 **2.3.0**，包内容与 2.2.8 一致（mihomo 内核、GeoSite/GeoIP、tun-service 均未改）。
