# FISH Dock 官方插件 1.0.2

四个独立插件统一更新至 1.0.2，适用于 Windows x64、FISH Dock 1.1.0+ 和宿主 API 1。

## Magpie

- 随包原生服务升级至官方 **0.1.1709**，对应源码提交 `47175a68fffe7a01c596f016c0d0da00545b10a4`。原生二进制保持官方字节不变，SHA-256 为 `9c42c5759354188b001f7fda4ef626fb0ffff8c3f1d35bd7ac7c37851328f74c`。
- 纳入上游[静默流保活修复](https://github.com/yetone/magpie/commit/13f658a37da5aab8a4f6a198904e25f74243b5c1)：协议转换后的流已经开始回复、随后上游静默时，继续向客户端发送保活。静默最长持续 30 分钟，避免长推理请求因客户端一直收不到事件而结束。
- **版本由 Dock 插件管理**。启动前关闭原生自动检查、自动下载、自动重启和更新提示；管理页移除检查、下载及自动更新相关按钮与开关，并拦截原生更新 API。用户在 Dock 的插件页更新此插件。首次调整设置时保留同目录配置备份，渠道、账号及其他业务设置保持原值；损坏设置保留并提示处理。
- 设置损坏时给出准确的 `settings.json` 修复指引，保留原文件；设置原子替换前刷新到磁盘，并保留已有 UTF-8 BOM。已停用的原生更新历史按钮一并移除，避免无效错误提示。
- 修复内部插件页面在 Dock 嵌套框架中被祖先策略拦截的问题，仅允许准确的 Dock 来源，保留内部页面脚本、网络和存储隔离。
- 保留真实用户目录、自定义 Agent 路径及显式 Bun 路径的发现；原生自有资料使用插件的独立便携目录。

## Clash

- 支持多个独立订阅并存，使用稳定订阅 ID 和节点前缀，避免同名节点互相覆盖。
- 单个订阅更新失败保留上次有效内容；新增迁移、缓存事务、错误脱敏和后台更新状态处理。
- 页面保存草稿、抑制重复提交，提供单／双栏布局；停止时保留系统代理原值恢复与失败重试能力。
- 默认路由在有启用订阅时为 `MATCH,PROXY`，无启用订阅时为 `MATCH,DIRECT`。移除旧默认 `GEOIP,CN,DIRECT`，健康检查默认关闭。订阅接受 mihomo 可解析的代理 YAML/JSON，不转换分享链接或 base64，也不接管完整配置中的 DNS、TUN 和 rules。

## 飞书与 OFM

- 飞书清除机器人增加页内确认；损坏配置与业务失败提供明确反馈，失败保留原凭据，界面保留未保存输入。
- OFM 改进分类数据目录与 Windows 路径验证，生命周期和临时目录跟随插件数据根。OFM 继续属于灰度，完整登录、项目绑定及真实模型调用尚未开放。

## 通用修复

- 随包服务路径跟随插件升级；用户明确指定的自定义服务路径保持原值。
- 启动可取消，停止回收本插件拥有的进程；启动错误使用固定错误码，不暴露密钥或上游原始日志。
- 发行构建检查必需运行时，输出到新目录，逐项核验 ZIP CRC、资源 SHA-256、页面入口和 npm 内归档字节一致性。

## 验证记录与边界

- 四插件最终整合回归：**64 项全部通过，0 失败、0 跳过**，同时启用真实 Magpie、mihomo、OFM、宿主 SDK 与隔离 Edge 检查。
- 真实官方 Magpie 0.1.1709、本机合成中转 `/tenant/api/v1`：Responses 客户端转换到 Chat 上游，静默期间收到两次独立保活后正常完成，上游请求计数为 1。同一夹具下旧随包二进制等待保活超时，验证升级前后差异。
- 隔离 Edge：准确 Dock origin 下内部插件加载、权限隔离、设置页更新按钮与开关移除通过；停止、重启、旧 token 失效、新地址生效及设置保留通过。
- 真实 mihomo 和 OFM：合成资料下的格式校验、启动/停止与管理页检查通过。npm 四包使用 Node 24.21.0 完成发布清单预检。
- 尚未在用户的真实中转账号或真实 Dock WebView2 中复现截图中的具体 25～27 秒失败。因此本版确认修复静默流缺陷，不宣称所有中转站错误、EOF、限流或协议错误均已解决。真实飞书消息、系统代理接管、用户订阅连通及真实模型业务调用仍需用户环境验证，相关 issue 保留开放。

下载后核对同版 `SHA256SUMS.txt`，再从 Dock 插件页导入对应 `.fish-plugin`。停用和卸载保留插件资料。
