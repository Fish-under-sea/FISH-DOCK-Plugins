# Magpie 2.0.3

**本次只发 Magpie 一个包**（`magpie.fish-plugin` 2.0.3，exe 版本 `magpie v0.1.2336+fish.4`）。Clash 仍是 2.0.2，飞书与 OFM 仍是 2.0.1——各自那三份包不改。

## 讯飞签到：一天一个号，一次 400

签到页里 `Loom (讯飞)` 以前是 **4 个账号全签、今日积分 0**：厂商一次只认一个账号，多号同签额度对不上；插件不报积分，页面就永远显示 0。

现在按维护者定的口径改成**实得**：

- **只签一个号**：同一厂商只留排在最前面的那个登录，其余账号仍可登录，只是不参与签到。账号列表与签到动作共用同一份裁剪（`pluginCheckinProviders`），所以页面上看到几个号，就只会签几个号。
- **一次固定 400**：插件报了积分（正数）就按它报的；没报就按厂商口径记 400，不再显示「0 今日」。
- 判定用 provider id 前缀 `loomy`，`loomy` 与 `loomy-plugin` 两种写法都认；`loom`、`qoder`、`zcode`、`autoclaw` 等不会被误伤。

实现放在 `fish.4` 补丁里（`internal/provider/plugin_checkin.go` 的 `loomyAccounts` / `loomyCredit`），并补了三条用例：只留第一个账号、别的厂商一个都不裁、400 的取值规则与 id 前缀边界。

## 签到页补了两家的标志

- **讯飞**：用 <https://www.iflyrec.com/> 首页「科大讯飞 iFLYTEK」标志**左侧的 X 形符号**，白底转透明后重采样到 64×64——签到页的格子只有 22×22，横排字放进去只剩一条糊线。落盘 `logos/loomy.png`，另放一份 `loomy-plugin.png`（provider id 有过两种写法）。
- **ZCode**：照搬 magpie 自带的 `zcode.png`，保留原图标，和 AutoClaw 的蓝圆区分开。

素材来源与裁切范围写在 `page-plugins/page-checkin/page/logos/README.md`。

## 升级：请用「卸载 → 安装」

Magpie 的 `credentials/magpie-runtime/` 里有 400 MB 以上的便携运行时（622 个文件），宿主在写「更新前回滚点」那一步必失败（[FISH-Dock#34](https://github.com/Fish-under-sea/FISH-Dock/issues/34)），**点「更新」不会成功**。卸载会保留 `%USERPROFILE%\.fish-dock` 下的账号、订阅与插件设置，重装后接着用。
