# Magpie 插件 1.2.2

签到页视觉与积分显示收尾。宿主 exe 与 1.2.1 相同（`eb674e34…`），只更新随包页面。

## 更新

- **厂商 Logo 真图上线**：签到页每个厂商显示官方标志，不再只是首字母色块。
  - 内置：WorkBuddy、MiniMax Code、Qoder / Qoder CN
  - 社区插件自带：CodeArts（华为红标）、商汤小浣熊
  - 官方站：Trae CN（trae.ai）、AutoClaw / AutoClaw 国内（Z.ai）
  - 页面按 `logos/<id>.svg` → `.png` → `.webp` 顺序取，缺图自动退回色块；`workbuddy.svg` 补齐 `viewBox`，不再被裁一半。
- **去掉「未告知」**：厂商不回报签到数额时，账号行不再显示「未告知」，头部也不再显示「N 项未告知」。
- **已知固定额度**：CodeArts、商汤小浣熊每个账号每天固定 +100，直接以 `+100` 计入今日积分（用户实测）。
