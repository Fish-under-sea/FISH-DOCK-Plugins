## 二、#24 收尾

### 1）设置页选择器

- `设置 → 模型` 里 Image generation 那一页之后，新增**「语音模型」与「向量模型」**两行（`renderSpeechAndEmbed`）：各自列出该类可用模型（`gateway.Speakers` / `gateway.Embedders`，即各自分区里勾选的那些），选择器组件、交互与图像那行完全同款；
- 视频模型不单独开行：视频生成走的就是 Image generation 的 MCP 服务器（`generate_image` / `generate_video` 工具），挑视频模型仍在那一行里；
- 设置项落在 `settings.json` 的 `speechModel` / `embedModel`（校验：必须是 `provider/model` 形式或空）。

### 2）`/v1/models` 的 `kind` 补值

- `kind: "audio"`（`X-Magpie-Speakers` 头请求，`speechObjects`）与 `kind: "embedding"`（`X-Magpie-Embedders` 头请求，`embedObjects`）：另一台 magpie 或任意客户端按这两个头就能拿到语音/向量模型列表，各自带 `modalities` 声明，不混进对话列表；
- 两个新头与既有的 `X-Magpie-Drawers` / `X-Magpie-Videomakers` 同款语义：不发的客户端什么都不会多看到。

## 三、签到「未告知」的惯例值

签到成功但插件没报积分的（`outcome` 是 `claimed` / `done` 而 `credit <= 0`），`credits` 那一份按**「签到到账 +100」**补一个惯例值；插件一旦报了真数值（`credit > 0`）就用真值，不覆盖。`dailyCredits` 与 `today` 保持原值——「今日额度」那一栏仍是「未告知」，只有「今日已得」从空白变成惯例值。改动在 `plugin_checkin.go` 与 `checkin_view.go`，注释里写明了口径。

> 这条只进 `CheckinViewState`（宿主侧聚合视图）。别的机器没有这个功能，是因为它们还在跑官方版 magpie——这条跟随我们的 `fish` 补丁走，装 2.2.0 的包才有。

## 四、路由组「图片输入」声明

路由组编辑页在「推理档位（Levels）」下面新增一行**「图片输入（Image input）」**，逻辑与档位同款的三态分段：

| 档位 | 含义 | 生效 |
| --- | --- | --- |
| **成员共有**（默认） | 跟随成员：有一个能看就算能看 | 既有行为，`Images` 留空 |
| **是** | 声明支持，即便成员都不认 | `Images = true`，Agent 被告知支持 |
| **否** | 声明不支持 | `Images = false`，带图请求被拒 |

数据层：`provider.Group` 新增 `Images *bool`（三态）与 `ImagesSaid string`（编辑器的档位），组聚合时用户的话覆盖成员的话（`group.go`）；`cloneGroups` 深拷贝了新指针字段（`TestCloneGroupsSharesNothing` 盯着）。

## 五、中转站探针：图标分工修正
