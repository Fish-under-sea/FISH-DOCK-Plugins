## 二、改动

### 1）NearToken 宿主通道（#21）

页面插件跑在 `sandbox allow-scripts` + `connect-src 'none'` 的帧里，出站请求只能由 magpie 代发。本版把 `neartoken:*` 八条加进 `PageCalls` 并接到 `internal/neartoken/`：

`neartoken:state` / `connect` / `cancel` / `open` / `disconnect` / `refresh` / `usage` / `topup`

同时带一条测试 `TestNearTokenCallsKept` 钉住 `callsKeeping` 不把这八条静默丢掉（历史上就是这一步丢的，页面只表现为「NearToken doesn't ask for neartoken:state」）。插件包 `@fish-under-sea/magpie-neartoken@0.1.5` 无需改动。

### 2）插件页超链接（#20-①）

**根因**：宿主给插件页的帧是 `sandbox="allow-scripts"`（`FISH-Dock/app/src/pet/extension-page.js:98`），既没有 `allow-popups` 也没有 `allow-top-navigation`，所以页面里任何 `<a href>` 点了都不会有反应——不是 magpie 拦的。

**本版做法**：magpie 增加一条宿主调用 `magpie:open-external`，页面把链接交给它，由 magpie 用系统默认浏览器打开（只认 `http/https`，`file:` / `javascript:` / `data:` 一律拒绝）。内置「中转站探针」的操作教程链接已经改用它。

**没有改 Dock**：框架级的 sandbox 限制仍在，已在主仓开 issue 记录（插件页缺少 `allow-popups`，任何插件的 `<a>` 都打不开）。第三方页面插件若要在自己页面里放外链，调用 `magpie:open-external` 即可。

### 3）中转站探针：图标与界面重做

- **图标**：原来是 109 KB 的灰色位图，改成与签到页同款的描边矢量图标（`stroke="currentColor"`，暗色下即白色），`magpie.icon` 与 `page.icon` 都指向 `page/icon.svg`；

> 更正（2.1.7）：这一条在 2.1.6 只把 `page/icon.svg` 落进了包，`package.json` 的那两处没接上，侧边栏还是兜底灰方块；接线与图钉图标见 [2.1.7](2.1.7.md)。
- **布局收紧**：卡片内边距 14→12、卡片间距 14→10、标题 20→18、表格行高压缩，首屏不再大片留白；
- **操作教程**：底部折叠块「操作教程（点击查看）」，七步走完从填地址到读结论，附 Anthropic / OpenAI 官方文档链接（走 `magpie:open-external`）；
- **探针表**：表头与行距统一，状态列等宽字体，说明列可换行。

> **功能现状说明（如实）**：这一版只做了界面与图标，**没有改探针的判定逻辑**。用户反馈「探针使用貌似有问题」，目前掌握的证据不足以定位到具体探针（B1 签名重放 / C1 计数对账 / C2 跨代 tokenizer 三条依赖站点真实返回），需要一次带真实中转站的复现（地址 + 模型 + 返回原文）。已在 issue 里留了复现要求，下一版处理。
