# Magpie 1.1.1 / Clash 1.0.4：自启动接口修正与签到页改进

适用于 FISH Dock **1.2.2** 及以后（自启动开关依赖宿主新接口）、Windows x64、宿主 API 1。仅 Magpie 与 Clash 升级；飞书与 OFM 保持 **1.0.2**。随包 Magpie 原生程序仍为官方 **0.1.1709**，字节与许可证未变。

## 为什么有这一版

1.1.0 给网关页加了「自启动」开关，但它调用的 `host.autostart` 会被 Dock 的页面桥按设计丢弃（`host.` 与 `plugin.` 前缀留给插件后端），消息既不成功也不报错，前端 Promise 一直挂着——开关停在禁用状态，点不动。

宿主 1.2.2 把接口改名为 `dock.autostart`。本版把 Magpie 网关页与 Clash 内核页都改成新名字：打开页面即读到当前状态，点击立即生效并写回宿主注册表，失败会回滚勾选并在页面报错；宿主早于 1.2.2 时开关自动隐藏。

## Magpie 1.1.1

- **「刷新今日积分」有反馈**：点击后按钮变为「正在刷新…」并显示旋转指示，期间禁用，刷新完成再恢复。
- **厂商分组可折叠**：点分组标题（或聚焦后按 Enter / 空格）展开或收起该组账号，标题右侧有 ▸ / ▾ 指示，互不影响。
- **分组前有厂商标记**：按厂商 id 取稳定色块并显示名称首字，等 magpie 侧提供真实图标后可直接替换。
- 内置副本同步到 `page-checkin` **0.1.1**；写动作、签到契约与 1.1.0 一致。

## Clash 1.0.4

- 内核页「自启动」同步改用 `dock.autostart`，其余行为与 1.0.3 相同。

## 验证

- 签到页 `node --test --test-isolation=none test/view.test.mjs` 7 项通过；`node --check` 对 `app.js`、`view.js`、网关页与 Clash 页均无语法错误。
- 打包产物解包复核：`magpie.fish-plugin`（45,646,041 B）含 `plugins/magpie/page-plugins/page-checkin/page/{app,view}.js` 与 `shared/gateway-page.js` 的 `dock.autostart`；`clash.fish-plugin`（12,209,345 B）含 `plugins/clash/page.js` 的 `dock.autostart`。

## 升级

Dock 升到 1.2.2 后，在「插件」页对 Magpie 与 Clash 点更新即可。原生程序、账号与订阅资料保持原位。
