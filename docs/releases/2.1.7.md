## 二、改动

### 1）NearToken：宿主让出供应商（#22）

**根因**：`@fish-under-sea/magpie-neartoken` 从 0.1.7 起包里多了 `index.mjs`，它同时是 magpie 的 provider 插件（`auth` 设备授权 / `provider.models` / `auth.usage` / `auth.icon`），provider id 仍是 `neartoken`；而 2.1.6 补进来的 `internal/neartoken` 还按老路子，登录成功后 `provider.Save` 一条 key+URL 供应商，两边撞在同一个 id 上。

撞的后果是宿主侧那条盖住了插件那条：

| 现象 | 原因 |
| --- | --- |
| 「重新获取模型」报 `no model list: https://neartoken.cc/v1/models: no models listed…` | 宿主侧那条没有 `ModelsURL`，magpie 去问站点 `/v1/models`；该端点按令牌分组过滤，很多账号回空 |
| 供应商卡是灰色立方体 | 宿主侧没写 `Icon`（`Icon` 必须是 `icons/` 里的 `file:<name>`，不是外链） |
| 模型只有七十来条、生图/视频模型不见了 | 宿主侧只写了聊天模型，没标 `Draws`/`Films` |
| 模型名后面没有分组与倍率 | magpie 的模型表一行一个模型，宿主侧没把「分组 × 模型」折进去 |

**本版做法**（issue 里的 A「让出供应商」）：

- `internal/neartoken` 新增 `handoff.go`：插件在场（`plugin.Listed()` 里有 id 为 `neartoken` 的 provider）时，宿主**不再** `provider.Save` 一条 key+URL 供应商、也不再 `catalog.SaveLive` 写模型表；
- 从页面连上的令牌交给插件自己的 auth（`plugin.Import`，形状照插件 `auth.methods` 回的那份：`type/access/refresh`），供应商页的模型行、分组倍率、图标、余额全部改由插件给；
- 老用户升级：`providers.json` 里那条宿主建的供应商会把钥匙先搬进插件 auth，搬成功才删掉那一条（搬不动就留在原地，钥匙不丢）；页面在那之前仍从老位置读，不会闪成「未连接」；
- 页面那八条 `neartoken:*` 改从插件凭据里读令牌（`plugin.Auths`），不再读 `providers.json`；
- 断开连接：站点撤令牌 + 删插件凭据（`plugin.SignOut`）+ 删宿主侧那条（含它写下的模型表），一样不留；
- 插件不在场（0.1.5 及更早的页面插件、或只装了页面那半边）时保持原来的做法：一条 key+URL 供应商，页面照旧能用。

`internal/plugin/page.go` 的 `PageCalls` 八条 `neartoken:*`、站点端点、错误码 `DSH_TOKEN_REQUIRED`、确认页路由都没动。

### 2）中转站探针：图钉图标

2.1.6 把探针的图标换成了描边矢量，但 `magpie.page.icon` 那一条没落到 `package.json` 上——侧边栏里「中转站探针」还是 magpie 兜底的那个灰方块。本版：

- 图标换成**图钉（📌）**：24×24、`stroke-width: 2` 的描边，与自动签到的日历同款；
- **深浅两套颜色写在文件里**：侧边栏与插件列表都是 `<img>` 加载，`currentColor` 在那里没有父级可继承、恒等于黑，所以在 SVG 里用 `@media (prefers-color-scheme: dark)` 切 `#111111` / `#F2F2F7`（窗口本来就跟着系统配色走，服务端不必猜主题）；
- `magpie.page.icon`（侧边栏，走 magpie 的页面图路由）与 `magpie.icon`（包级，走 `LocalIcon` 的 `file:` 兜底）都指向同一个 `page/icon.svg`；
- 删掉包里那张 109 KB 的灰色位图 `page/icon.png`。

`page-relay-probe` 因此升到 0.1.2。

## 三、验证

- 补丁：对 pristine `v0.1.2732` `git apply --check` 干净，`--binary` 生成；
- Go 侧：`internal/neartoken` 单测全绿，新增 5 条盯住「插件在场时钥匙归插件」「宿主侧那条会被让出」「插件不在场时保持老做法」「断开两处都不留」；
- 页面侧：`page-relay-probe` 单测 5/5 与 `node --check` 通过；
- 图标：Edge 无头 + CDP `Emulation.setEmulatedMedia` 各截一张——浅色下描边 `#111111`、深色下 `#F2F2F7`，`<img src=icon.svg>` 里的媒体查询确实生效；顺带发现并修掉 `style` 注释里的 `<img>` 把 SVG 写成非法 XML（`img` 加载会整张失败）这个坑；
- 包内一致性：`verify-release` 通过（`fish.magpie` 2.1.7 / 84 个文件 / 33,307,148 B）；发行后实测下载地址返回 200 且字节数一致；
- 环境噪声：本机 `internal/gui` / `internal/plugin` 的部分用例依赖符号链接权限与命名管道（沙箱禁），与本次改动无关，逐条记录在案。

## 四、未验证

- **没有真实 NearToken 站点验收**（需要站点账号）：插件接管后的模型行、图标、余额、生图/视频分类，都是代码层与单测层的结论；
- 图钉图标只核过「`<img>` 加载 + 深浅媒体查询生效」这两件事，没有在真实 Dock 窗口的侧边栏里逐像素看过。
