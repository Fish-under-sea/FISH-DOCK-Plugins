# 插件 2.4.0（Clash + Magpie）

> 本版把「外观」从常规页拆成独立分页，液态玻璃由开关改为按区域精细调节；Clash 新增同样口径的外观设置（背景图片 + 液态玻璃）；并修好 Magpie「在 Obsidian 打开」点了没反应。
> 校准：FISH Dock ≥2.0.0（Magpie ≥2.3.4）、宿主 API 1、Windows x64。飞书保持 2.2.0。

## 共同改动：液态玻璃的「数字即真相」

两边的液态玻璃都用同一套词汇，避免“两个插件两种说法”：

- 三个区域各有两项：**不透明度**（`fill`，百分比，100 = 实底）与**模糊**（`blur`，像素，0 = 不模糊）。
- 100% + 0px 就是原来的实底，所以「关闭」只是这组数字的一个坐标，不再是单独的开关状态；
  也因此**预设只是写入这组数字的快捷方式**，拖动滑块后自动变成「自定义」。
- 预设：关闭 / 轻透 / 均衡 / 自定义。
- 不支持背景模糊或 `color-mix` 的引擎（禁 GPU、远程桌面、旧 WebView）自动回到实底；
  `prefers-reduced-transparency: reduce` 与 `forced-colors: active` 一律回实底并关掉模糊。

## Magpie 2.4.0（原生标识 `v0.1.4262+fish.38`）

### 记忆「Agent 化」（M-A 到 M-E 全部完成，内置、不拆插件）

- 「从对话学习 / 每晚整理 / 做梦」的执行主体从「选模型」改为**选 Agent**：内置 `memory-agent` 的指令是我们那份记忆维护 AGENTS.md，产物经记忆 MCP 写回、只往 vault 白名单目录写。Magpie 的三处下拉与 Obsidian 插件的记忆任务都只显示 Agent 名字，模型不再出现在任何一处记忆下拉里（对话/整理选文仍按模型走，二者不混）。
- **注册表** `<magpie config>/memory-agents.json`：原子写 + 文件锁 + 坏文件不覆盖（读回上一份好文件并留 `.bad-<时间>`），首次启动自动写入两个预设——`memory-curator`（learn|organize）与 `dreamer`（dream），可改可删，删了能一键恢复。
- **执行器与沙箱**：工具循环带上限（40 步 / 单次 20 分钟 / 单轮 5 分钟），记忆工具 + 知识库只读工具 + 白名单写工具 + Agent 自己 `mcp.json` 里的 MCP；`os.OpenRoot` 限定库根，读 `wiki/ inspirations/ memories/`、写 `inspirations/ _digests/ candidates/ dreams/ logs/`，越界、`..`、绝对路径、软链与 junction 一律拒绝；scratch 每 run 一目录、结束即删，超 20MB 按最旧回收到 ≤20MB，且只清自己的缓存根。
- **派发与进度**（M-A3 / M-B）：`GET /api/memory/distill` 的 `models[]` 改为按角色过滤的 `agents[]`；`POST /api/memory/distill` 只收 `{on,agent,effort?,days?,dreamAgent?}`，Agent 不属于该角色或不存在即 400 且不落盘；`GET /api/memory/agents/status?role=` 与 `POST /api/memory/agents/{role}/run|stop` 提供 2 秒轮询的进度、逐条聊天/工具与停止；定时 learn/dream 改由同一派发路径触发。
- **审计与冲突**（M-D）：机器每次 `save/forget/remove/promote/status` 都往 append-only 的 `<config>/memory-audit.jsonl` 记一行（`{at,action,id,role,agent,result,scope,kind,error}`，不含记忆原文，超长截断，64 路并发也是整行）；对 `origin=user` 或用户编辑过的记忆，机器改其文字/kind/scope/why（或解 pin）一律拒绝，并把原因与用户原话（疑似密钥替换为 `[redacted]`）追加到 `<vault>/logs/memory-conflicts.md`，原记忆不动。审计写失败只记日志、不阻塞主流程。
- **Obsidian 插件**（M-E）：记忆任务（学习/整理/做梦）选 Agent，触发 run、2 秒轮询显示 phase/进度/逐条聊天与失败原因、可 Stop；写路径只允许 `Magpie 对话/<单层>.md`（拒绝 `/ \ .. ~`、绝对路径、控制字符、非 `.md`）；20MB GC 只计只删本插件自己产生的笔记（marker 或 `YYYY-…-<hex>.md` 命名，按 mtime 最旧优先），`memories/`、`wiki/` 与用户笔记绝不删；不新增出网。magpie 侧同一批 `status/run/stop` 经 `fish-vault` 的配套私令牌路由暴露给插件（`/api/fish-vault/memory/agents…`），沿用回环 + 私令牌 + 无 Origin。

### 设置 › 外观（新分页，位于「常规」与「额度」之间）

从「常规」迁入这九项：外观（主题）、强调色、背景图片、液态玻璃、界面字体、代码字体、色盲模式、减弱动态效果、加载时的喜鹊。
「常规」保留语言、网关模式、字号、托盘、登录项等行为类设置。

### 液态玻璃改为分区域调节

- 去掉原来那颗「液态玻璃 开/关」胶囊。
- 三个区域各自一组滑块：**侧边栏与标题栏**、**主界面（卡片/列表/字段）**、**浮层（菜单、抽屉、确认框）**。
- 主界面是重点：卡片与列表可以单独调透，侧边栏本就常与壁纸同底，可不动。
- 拖动时只改 CSS 变量（连续预览、不写盘、不重绘）；松手才保存，并且**只提交该区域**，其它区域不动。
- **壁纸与玻璃的配合**：有背景图片时，遮罩在玻璃开启时降到 45%（关掉玻璃回到 84%），否则 84% 的遮罩会把壁纸压得几乎看不见，玻璃等于没开。
- 旧版 `fishGlass: true` 的配置在读取时自动展开成 2.3.8 的样子（侧边栏/浮层透、主界面实底），升级不丢已选效果；
  `fishGlass` 字段保留为兼容位，实际状态由三组数字推出。

### 插件页握手：液态玻璃随主题一起下发

- 内嵌页面原有的 `magpie.theme` / `magpie.onTheme` 之外，新增 `magpie.glass` 与 `magpie.onGlass(fn)`：
  `{ on, regions: { sidebar, content, overlay }: { fill, blur } }`。
- 页面侧同时拿到 `--magpie-glass-<region>-fill/-blur` 与 `data-magpie-glass` 属性，便于插件页画自己的表面；
  与深浅色是同一条管线（`MutationObserver` → `postMessage`），不额外开握手。
- 这是「跟着 magpie 一起生效」的部分：Magpie 调自己的外观，内嵌插件页同步收到。

### 修复：在 Obsidian 打开没有反应

- 根因：magpie 的 `/api/open` 最终走 `rundll32 url.dll,FileProtocolHandler`（ShellExecute），而 magpie 由 Dock 以 `windowsHide` 启动、自身又没有控制台，
  继承下来的显示状态会把 Obsidian 的仓库窗口一起藏掉，只剩一个看不见的 Electron 进程。
- 修法：适配层在代理处**只接管本知识库自己的 `obsidian://open?path=` 链接**，用 `windowsHide:false` 直接拉起窗口；
  别的链接与外链原样交回 magpie。判据只认「本库根或其下 .md」，越界、多参数、别的协议一律不接管。
- 顺带把知识库链接的空格编码从 `+` 改为 `%20`（协议处理器按裸路径解析时 `+` 会被当成加号）。

## Clash 2.4.0

### 设置 › 外观（新分页）

- **背景图片**：PNG/JPEG/GIF/WebP，上限 2 MB，存在插件自己的 `config/appearance.json`；有「底图遮挡」滑块（0–95%）保证文字可读。
- **液态玻璃**：与 Magpie 同一口径的预设 + 三区域滑块（主界面卡片/订阅卡/TUN 框、顶栏与工具条、下拉与撤销条）。
- 只在页面自身生效，不写内核配置；内核运行中也能改。

## 材质更新（Liquid Glass）与字体颜色

- 两个插件的玻璃材质重做：底色仍由各区域的「不透明度 / 模糊」决定，另加 saturate/brightness 的折射观感、::before 双层柔光、::after 1px 渐变高光边（mask 挖空），贴近 iOS 26 的 Liquid Glass；参考并借鉴开源实现 [nikdelvin/liquid-glass](https://github.com/nikdelvin/liquid-glass) 与 [eirasmx/webglass](https://github.com/eirasmx/webglass) 的手法（未引入依赖）。真正的 Snell 折射位移（backdrop-filter: url(#filter)）目前只有 Safari 支持，Chromium 下用上述高光/柔光/折射色作等价近似。
- Magpie「设置 › 外观」新增**字体颜色**：自定义界面文字色（#rrggbb），留空跟随主题，深色主题可单独一套；首帧 lookCSS 即写入 `--fg`/`--fg-2`/`--muted`/`--faint`，避免闪烁。
