# 插件 2.3.1（Magpie）

> 只发 Magpie；Clash 仍是 2.3.0，包未动。
> Magpie 的 `magpie.exe` 重编到补丁 **`v0.1.3207 + fish.26`**（上游从 v0.1.3140 追平 67 个 tag）。
> 校准：FISH Dock ≥ 2.0.0、宿主 API 1、Windows x64。

## 模型分类：官方判定 + 用户自定义标注（#42）

上一版（#24）只给出了四个分区，判据只有一条——`catalog.ServesOf(id)` 按模型 ID 名字猜，猜不出就丢弃或当成对话模型。插件 provider 声明的模型更彻底：`plugin.Model` 没有 kind 字段，`capabilities.output` 里的 `audio` / `embedding` 只用来判「能不能聊」，于是 NearToken 那类插件报上来的语音、向量模型既不进分区、也不在对话列表，直接消失。

本版把分类的来源补齐：

- **插件自己的 kind 先说**：`plugin.Model` 新增 `kind`（`image` / `video` / `audio` / `embedding`），`pluginCatalog` 按它落 `Draws` / `Films` / `Serves`；`capabilities.output` 与模型 id 只作兜底。`kind: audio`（或 `embedding`）的模型不再混进对话列表，哪怕它同时声明了 `text` 输出。
- **用户可以自己标**：`settings.ModelKinds` 从 `image` / `video` 扩到 `speech` / `transcription` / `embedding` / `rerank`，插件 provider 也能标（`MarksServesKinds`）。模型 chip 右键的 **Makes…** 菜单从两项变六项。
- **设置页取数补齐**：`speakingOf` 收进插件声明的另一类模型（`PluginServing`），设置 → 图像的「语音模型 / 向量模型」两行不再只有自定义中转的 live 列表；判据统一走 `ServedAs`（用户标注优先，其次模型自己的列表）。
- **「其他模型」栏**：插件说某个模型「给的不是对话」却没说是哪一类时（`PluginUnkinded`），编辑器单列一栏，点一下就能归类——否则这些模型三种列表里都看不到。
- **顺带修一处**：设置页保存的字段白名单 `prefsKeep` 补上 `speechModel` / `embedModel`，不再靠后端 merge 兜底。

## 已知边界

- 真机 UI 未点验：设置 → 图像的「语音模型」下拉、编辑器「其他模型」栏需要装上本版后过一遍。
- NearToken 侧要配合：它的 `kind` 取值（`chat|image|video|audio|embedding`）本版已认；`kindOf` 对「能听音频但输出文本」的对话模型有误判，插件仓已开单（magpie-neartoken#1），修复前这类模型可能被标成音频。
