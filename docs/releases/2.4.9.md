# 2.4.9 发行说明

**Magpie** 升级到 **2.4.9**（追平上游 `yetone/magpie@v0.1.4530`，累计补丁 `v0.1.4530+fish.49` / Windows FileVersion `0.1.4530.49`，要求 FISH Dock ≥ 2.3.4），**Clash** 升级到 **2.4.9**（修复 Issue #57 沙箱 CSP 下壁纸上传必败问题并分离解码/超限报错，要求 FISH Dock ≥ 2.0.0），**飞书**保持 `2.2.0` 不变。

## 本版更新（Magpie `fish.49` · 基线 `v0.1.4530`）

- **上游追平至 `v0.1.4530`**：合入上游自 `v0.1.4344` 以来的全部网关、供应商、用量、资源库与界面修复（含 `videogen.js` 图像分辨率设置 `imageResolution` 等上游新增特性），重放 `fish.48` 254 个文件 / 450 个 hunk，人工消解 9 个文件 / 18 个冲突并导出新累计补丁 `magpie-v0.1.4530+fish.49.patch`。
- **液态玻璃覆盖表重扫**：针对上游新引入的样式表（7 份 CSS）重跑 `plugins/magpie/tools/glass-surfaces.mjs --write`，自动更新 163 条静态表面玻璃覆盖（`--card=127`、`--card-2=34`、`--bg=2`），保持 `.mchip`、`.rt`、`.connect .val`、`.mo-node .ic` 等手写高权重玻璃规则完整生效。
- **脚本预算同步**：`internal/gui/core_budget_test.go` 按实测代码字节数更新为 `appScriptBudget = 1_091_561` 与 `coreScriptBudget = 1_278_437`。

## 本版更新（Clash 2.4.9 · 修复 Issue #57）

- **修复沙箱 CSP 拦截 `blob:` URL 导致背景图片上传必败**（`plugins/clash/page.js`）：宿主下发的严格 CSP `img-src 'self' data:` 不允许加载 `blob:` URL，原 `URL.createObjectURL(file)` + `new Image()` 必然触发 `img.onerror` 导致任意格式/大小的图片均无法上传。现改为优先使用 `createImageBitmap(file)` 直接解码（并在 `finally` 中调用 `close()` 释放位图内存），在不支持 `createImageBitmap` 的环境下回退到 `FileReader.readAsDataURL(file)`（`data:` URL 在 CSP 允许范围内）。
- **分离壁纸失败文案并对齐真实预算上限**（`plugins/clash/page.js`、`shared/errors.mjs`）：将原先混入 `APPEARANCE_WALLPAPER_INVALID`（且误写为「2 MB 以内」）的四种失败拆开提示——文件类型不符走 `APPEARANCE_WALLPAPER_INVALID`（更新为「页面压缩上限 1.5 MiB / 存储上限 2 MiB」），解码损坏明确报「背景图片解码失败」，8 轮压缩后仍超 `1.5 MiB` 报「背景图片压缩后仍超过 1.5 MiB 传输上限」，后端保存错误保留原错误码呈现。
- **补充真实浏览器与契约回归**：在 `plugins/clash/page.browser.test.mjs` 新增「真实 sandbox 页面（严格 CSP）：外观背景图片上传」用例（真实 Edge + Playwright + 宿主 `img-src 'self' data:` CSP），同时在 `plugins/clash/page.test.mjs` 增加禁止回退 `URL.createObjectURL` 的静态契约守护。
