# Clash 2.0.9

**本次只发 Clash 一个包**（`clash.fish-plugin` 2.0.9）。Magpie 是 2.0.8，飞书与 OFM 仍是 2.0.1。

> 版本号跳过 2.0.8：它已经被这一轮的 Magpie 发行用掉了，Clash 接在 2.0.9。

## 1. 订阅改成单选：同时只跑一条

之前允许多条订阅同时启用，于是几家机场的节点会混进同一个组树，出问题时也说不清是谁的节点。现在：

- **点一张卡启用，其余自动停用**（存储里也只留一条 `enabled`）；
- 再点已启用的那张 = 停用，可以一条都不启用；
- 新增订阅默认不启用（第一条除外），要用就点它；
- 老配置里如果有多条启用，加载时只保留第一条，界面与内核看到的是同一个状态，下次点卡片时写回盘。

启动内核只用启用那一条的 provider。

## 2. 节点页去掉，测速搬到主界面，默认代理组是「自动选择」

- **「节点」页签删除**：搜索、按延迟排序、只看可用这些控件一起拿掉。
- 主界面「当前节点」卡现在是唯一的切节点入口：代理组下拉 + 节点下拉（下拉里直接带延迟），底下那行显示当前节点的延迟。
- **「测速」按钮就在这张卡上**：测当前组的全部节点（并发 6、上限 200），结果写回下拉与延迟行。
- 默认落在「♻️ 自动选择」组上，没有自动选择组时才落到第一个——多数人不想手挑节点。

顶部因此只剩三个页签：**概览 / 订阅 / 内核设置**，与「停止内核 / 刷新」仍然挤在同一行。

## 3. 超时不再显示成「0 ms」

`mihomo` 对不通的节点回 0 或空值，之前直接渲染成「0 ms」——看着像最快的节点。现在三态分明：

- 测出数值：绿 / 黄 / 红按 150 ms、400 ms 分档；
- 测过但超时（0 或空）：**红字「已超时」**，下拉里也写「· 已超时」；
- 从没测过：灰字「未测速」。

## 4. 版式：内边距回来了，字号只有三档

2.0.7 把内容区改成统一内滚容器时，`padding` 被覆盖成 0，于是订阅、节点、内核设置三页的标题和卡片全贴着面板边缘——这就是「字体没对齐、像溢出来」的来源。现在内边距回到 16px，只有概览（透明底的卡片网格）自己清零。

字号收敛成三档：标题 13px、正文 12.5px、次要 12px，不再出现 12 / 12.5 / 13 之外的微调。延迟三态、订阅标签、额度条文字一并归到这尺度上。

## 升级

Clash 的 `credentials/` 只有订阅地址与控制器密钥（几十 KB），用插件卡的「更新」可以直接升。若之前同时启用了多条订阅，升级后只剩第一条处于启用状态，其余仍在列表里，点一下就能切。
