# Magpie 插件 2.3.8

> **液态玻璃功能本版暂不可用，请勿开启。** 当前效果不符合使用要求，默认关闭；本版不以玻璃效果可用作为交付承诺。

本版仅升级 Magpie。Clash 保持 2.3.6，飞书保持 2.2.0。由于集成原生目录选择能力，**本版 Magpie 要求 FISH Dock ≥ 2.3.4**，宿主 API 1、Windows x64。旧宿主请先升级，其他插件兼容要求不变。

## 修复 Obsidian 打开后“退出”

旧入口错误地用 `windowsHide:true` 启动 GUI 应用，导致 Obsidian 仓库已加载但窗口被隐藏；用户关闭仓库选择器后，看起来像应用退出、知识库打不开。

本版改用正常可见窗口启动，保留独立进程与静默标准输出，但不隐藏 GUI。新增启动失败和重复打开的回归测试，不重写已有仓库登记。

真实 Obsidian 1.15.1 的隔离实测复现了旧参数 `visible:false`，修复参数为 `visible:true`，均无渲染异常。用户现有库的隐藏窗口已恢复可见，没有删除缓存、修改笔记或强杀进程。请更新插件后再使用“在 Obsidian 打开”；旧版入口仍可能再次隐藏窗口。

## 共享知识库提示可关闭

顶部提示新增关闭按钮。关闭状态保存在插件持久配置中，刷新、重开页面或服务重启不再自动弹回。需要时从“服务设置 → 共享知识库与 Obsidian”重新查看，手动查看不清除已关闭记录。配置写入失败会显示错误并允许重试，不虚报永久关闭。

## 预装百度搭子 DuMate

默认预装基线新增 `magpie-dumate`，经核实来源 `github:R227BOUT/magpie-dumate`，provider id `dumate`、MIT 许可。由 Magpie 自身安装/更新循环获取，不随包分发个人已安装目录或凭据。已有插件、钉住的 Git 引用/版本、停用状态和 options 保留；用户移除后不因重启反复补回。不自动代用户登录或发起真实供应商请求。

## 集成网页模式文件夹接力

兼容接入 [Fish-under-sea/FISH-DOCK-Plugins#51](https://github.com/Fish-under-sea/FISH-DOCK-Plugins/pull/51) 的功能：原生管理页“打开文件夹/选择备份目录”接力到 Dock 的系统目录接口。保留现有知识库、记忆和配对桥接。

只接受原生白名单路由已校验返回的路径，不使用页面提供的任意路径；跨站、远端来源、错误方法被拒绝。限制缓冲大小并保留超限响应完整透传；取消后不保存迟到的目录结果。宿主已显示的系统对话框可能仍需用户关闭，不宣称 SDK 提供了原生取消能力。

此为代码兼容集成，不代表已在 GitHub 合并或关闭该 PR。
