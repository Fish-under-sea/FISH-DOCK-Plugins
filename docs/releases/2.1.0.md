# 2.1.0 · 三个插件对齐

**这一版把飞书、Clash、Magpie 一起升到 2.1.0**，OFM 仍是 2.0.1（该插件自 10 月 25 日起暂停维护，不跟随）。

只有 Magpie 有实质改动；飞书与 Clash 是对齐版本号，包内内容与 2.0.1 / 2.0.9 一致。

## Magpie：图标接管补完了最后两块

2.0.8 把插件页、供应商页、侧边栏、路由与用量卡片的图标接管了，但**「扩展 → 插件 → 已安装」这一页没管**——它读的是包自己的 `magpie.icon`，走的是另一条路。这一版补上：

- **已安装列表也认品牌图标**。列表里一行说的是「包」，一个包可能注册好几家（`trae-cn` 与 `trae-global`），取其中第一个命中素材的。
- **包内的图也收**。`magpie.icon` 写成包内相对路径（`page/icon.png`）时，upstream 的 `InstalledIcon` 是不认的——它只收 `https://` 与 `data:` 这两种页面自己加载得了的形式。窗口这边能读文件，于是按内容存成一张普通图标再画，于是「自动签到 / 中转站探针」不再是那个灰书页。
- **图标画大一点**。列表行 18px → 23px、卡片 20px → 24px、大头图 25px → 30px。缩到 18px 的插画看不出是什么，放大才认得出。

## Magpie：两个页面插件的图标各归各位

2.0.5 把品牌立绘塞进了 `magpie.page.icon`，于是**侧边栏**那两个页面入口变成了我们的图——那是理解错了地方。

这一版改回来：

- `magpie.page.icon` → 恢复各自的 `page/icon.svg`（自动签到是可勾选的日历），中转站探针恢复成不声明图标；
- 品牌立绘挪到 `magpie.icon`（包级），**只出现在插件列表里**，侧边栏不再受影响。

## 签到页

`page-checkin` 0.2.5 起顶部有一行「预装插件美化」开关（默认开），这一版不变；开关走的两条调用是 `brand:status` 与 `brand:set`。
