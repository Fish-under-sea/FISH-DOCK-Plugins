# Clash 2.0.6

**本次只发 Clash 一个包**（`clash.fish-plugin` 2.0.6）。Magpie 仍是 2.0.5，飞书与 OFM 仍是 2.0.1，那三个包不动。

## 1. 出口 IP 永远显示「当前运行时不支持查询出口 IP」

`proxiedGet`（经代理口发请求的那段）确实写在 `runtime.mjs` 里，但 `createRuntime` 组装返回值时漏了它——`service` 里 `runtime.proxiedGet` 永远是 `undefined`，于是每次都落到「当前运行时不支持查询出口 IP」这条兜底分支，红字常驻。

现在把它交出去，并且把两种失败分开：

- 运行时**真的**缺能力 → 「当前运行时不支持查询出口 IP」；
- 能力在、代理不通 → 「查询服务无响应，请检查代理连通性后重试」。

这条提示也不再渲染成红色告警：查不到出口 IP 是状态，不是错误。

## 2. 概览只显示当前那条订阅

之前把**所有已启用订阅**整块铺在概览上，两条订阅就是两套「名称 / 最近成功 / 额度条 / 更新按钮」。现在概览只讲一条：

- 取「当前节点所属的订阅」（沿代理组的选中项逐层解析到叶子节点，看它带哪个订阅 ID）；
- 取不到（选的是 DIRECT、自动选择这类不是订阅的节点）就落到第一条已启用；
- 其余订阅折叠成一行：`另有 N 个已启用订阅，这里只显示当前节点所用的那条；切换在订阅页点卡片`。

## 3. 订阅页：点卡片即启用/停用

按 Verge 的做法改了交互：不再有「启用 / 停用」按钮，**直接点订阅卡片**就切换，启用中的卡片蓝色描边 + 浅蓝底色，`role="switch"` + `aria-checked` 表达状态，键盘回车/空格同样可切。

卡内的「更新 / 编辑 / 删除」不触发切换（点击目标是按钮时不冒泡）。内核运行中整卡不可点，卡片底部写明「内核运行中：先停止内核再切换订阅」。

## 4. 规则与连接终于有内容

之前这两页只有一个「读取详情」按钮加一段 JSON，后端还只回了 `type` 与 `proxy`——`payload`（规则真正在拦什么）根本没回，页面上等于什么都没有。现在：

- **规则**：`类型 / 内容 / 策略` 三列对齐，带搜索框与总数，几千条也能扫；
- **连接**：上行/下行汇总 + 逐条连接（域名、命中的规则、链路末节点、每条上下行流量），带搜索与总数；
- 进页自动读取一次，之后用「重新读取」；内核启停后自动清空重读，不会拿旧数据糊上去。

隐私与体积：连接条目不回进程路径这类本机信息，只回展示需要的字段；列表上限 200 条，`/connections` 的响应上限单独放宽到 8 MiB（连接多时原始响应本来就超过 2 MiB）。

## 5. 版面

- **去掉单栏 / 双栏切换**：宿主面板本来就窄，双栏只是把 8 张卡片挤成两列。
- **「启动内核 / 刷新」挪到标签页下面**，贴着它们要作用的内容，不再占标题栏。
- **概览自己滚动**：卡片区 `max-height:min(68vh,560px)`，信息再多也不会把标签页和设置顶出屏幕。

## 6. 页面版本跟随插件版本

页头那行不再有独立的「页面 v1.4.1」。后端读包内 `plugin.json` 的 `version`，放进 `view.pluginVersion`，页面显示 `内核 v1.19.15 · 插件 v2.0.6`——版本号只有一个来源，不会再出现「插件升到 2.0.x，页面还写着 1.4.1」的错觉。

## 7. 系统信息补全

从三行（操作系统 / 运行模式 / 页面版本）补到：操作系统 + 架构、处理器（型号 · 核数）、内存总量、运行模式、内核来源（内置 mihomo / 自定义路径）、插件版本。

## 升级

Clash 的 `credentials/` 里只有订阅地址与控制器密钥（几十 KB），撑不爆回滚点，用插件卡的「更新」可以直接升。升级失败时卸载重装即可：账号、订阅、节点缓存都在 `%USERPROFILE%\.fish-dock` 下，不会被删。

## 已知未做

- 规则页只读不写：还不能在页面上增删改规则，改规则仍要动订阅或内核配置。
- 连接页不提供「断开某条连接」：控制器有接口，但先看用户是否真的需要。
