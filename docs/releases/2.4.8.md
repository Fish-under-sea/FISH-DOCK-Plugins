# 2.4.8 发行说明

**Magpie** 升级到 **2.4.8**（随包核心 `v0.1.4344+fish.48`），集中修复液态玻璃界面残留与多处细节回归，同时保持 **Clash**（`2.4.7`）与 **飞书**（`2.2.0`）不变。

## 本版更新（Magpie `fish.48`）

- **供应商页底部栏**：去除 `#view-providers .after-list::before` 遮罩背景条，仅保留 `+ 添加供应商` 液态玻璃按钮。
- **路由页卡片与未用连线**：左右两栏卡片（`.rt-node` 与 `.rt-accts li`）统一为 `.rt-hub` 晶透玻璃质感，选中账号使用高对比选中高亮，空白占位维持透明；未使用或静态连线改为白色，保留 `.live` / `.lit` / `.rt-flows` 激活态流光动画。
- **脱敏页节点图标**：移除 `.mo-node .ic` 外围黑圈背景与阴影，保留 `.msk-hub` 中间节点样式。
- **网关页玻璃化**：`.connect .val` 主容器玻璃化且保持内层 `.connect .val > .val` 透明，避免双重框线；统一 `#view-gateway .find`、`#gatewayKeys .klf input`、`.sheet .find` 与模型配置徽章 `.row.model .minfo .badge, .rt-gedit .fbrow .minfo .badge` 为液态玻璃样式。
- **资源库与记忆审阅同步**：提高未选中 Agent（`.lib-ag:not(.on):not(.blocked)`）单色图标可见度，同时保留选中后全彩态区分；`distillRow()` 改为依据实时候选记忆条目计数展示待确认状态（全部审阅后切换为已审阅提示，存在待确认项时提供一键跳转审阅），并同步补全 `zh`、`zh-TW`、`ja`、`de` 翻译。
- **侧边栏、弹层菜单与模型胶囊**：提高侧边栏项（`#nav button[data-view]`、`#prefs`、`.side-gw`）与协议/时间跨度菜单（`.proto-menu .pm-item`、`.rm-item`、`.pop li`）悬停、聚焦与单选选中态样式优先级；模型选择胶囊 `.mchip` 及其自动/选中态切换为无深色描边的晶透玻璃胶囊。
