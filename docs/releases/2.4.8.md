# 2.4.8 发行说明

**Magpie**（`2.4.8`，随包核心 `v0.1.4344+fish.48`）与 **Clash**（`2.4.8`，随包内核 `mihomo v1.19.15`）合并在 `v2.4.8` 发布（`clash.fish-plugin` 与更新后的 `SHA256SUMS` 并入同版 Release 资产），**飞书**保持 `2.2.0` 不变。

## 本版更新（Clash 2.4.8）

- **通用双模式高性能 DNS 与嗅探管线**（`plugins/clash/runtime.mjs`）：统一提取 `buildDnsConfig()` 与 `buildSnifferConfig()`，无论启用系统代理还是 TUN 虚拟网卡，均开启 `ipv6: false`、`sniffer`（含顶层 `override-destination: true`）与优化 DNS；常规代理模式使用真实 IP DNS，启用 TUN 时自动附加 `fake-ip`、`fake-ip-filter` 与 TUN 配置。补全 `direct-nameserver` 与 `respect-rules`，并在具备本地 Geo 数据且存在启用订阅时启用 `fallback` 与 `fallback-filter`；无 Geo 数据时自动跳过 `fallback-filter`，避免离线启动触发 MMDB 下载超时。
- **独立 GitHub / npm 分流与直连规则修正**（`plugins/clash/runtime.mjs`）：将 `GEOSITE,github` 与 npm 注册表域名（无 Geo 时匹配核心 GitHub / npm 域名后缀）前置并划入新增的 `🐙 GitHub` 代理组（`[🚀 节点选择, DIRECT]`），优先于 `GEOSITE,microsoft` 匹配，解决访问 GitHub 与更新插件缓慢或失败的问题；补充 `🤖 AI 服务` 规则（`GEOSITE,anthropic`、`claude.ai`、`copilot.microsoft.com`、`gemini.google.com`、`aistudio.google.com`）；将 `DOMAIN,cn.bing.com`、`GEOSITE,microsoft@cn` 与 `GEOSITE,apple@cn` 前置走 `🎯 全球直连`；在 `GEOIP,cn` 后拦截海外 UDP 443（QUIC），避免浏览器长期卡在 QUIC 握手。
- **过滤订阅信息伪节点与强化故障切换**（`plugins/clash/subscriptions.mjs`、`plugins/clash/runtime.mjs`、`plugins/clash/tun.mjs`）：通过 `DUMMY_NODE_FILTER` 为运行态 provider 配置 `exclude-filter`，剔除剩余流量/到期时间/官网公告等伪节点（订阅列表校验原始节点计数不受影响）；`♻️ 自动选择` 收紧至 `interval: 90`、`timeout: 3000`、`tolerance: 50`、`max-failed-times: 2`、`expected-status: '204'`，并新增 `🩺 故障转移`（`fallback`）代理组；`waitFor()` 状态等待超时由 `8000 ms` 提升至 `12000 ms` 以兼容冷加载 GeoIP/GeoSite。

## 本版更新（Magpie `fish.48`）

- **供应商页底部栏**：去除 `#view-providers .after-list::before` 遮罩背景条，仅保留 `+ 添加供应商` 液态玻璃按钮。
- **路由页卡片与未用连线**：左右两栏卡片（`.rt-node` 与 `.rt-accts li`）统一为 `.rt-hub` 晶透玻璃质感，选中账号使用高对比选中高亮，空白占位维持透明；未使用或静态连线改为白色，保留 `.live` / `.lit` / `.rt-flows` 激活态流光动画。
- **脱敏页节点图标**：移除 `.mo-node .ic` 外围黑圈背景与阴影，保留 `.msk-hub` 中间节点样式。
- **网关页玻璃化**：`.connect .val` 主容器玻璃化且保持内层 `.connect .val > .val` 透明，避免双重框线；统一 `#view-gateway .find`、`#gatewayKeys .klf input`、`.sheet .find` 与模型配置徽章 `.row.model .minfo .badge, .rt-gedit .fbrow .minfo .badge` 为液态玻璃样式。
- **资源库与记忆审阅同步**：提高未选中 Agent（`.lib-ag:not(.on):not(.blocked)`）单色图标可见度，同时保留选中后全彩态区分；`distillRow()` 改为依据实时候选记忆条目计数展示待确认状态（全部审阅后切换为已审阅提示，存在待确认项时提供一键跳转审阅），并同步补全 `zh`、`zh-TW`、`ja`、`de` 翻译。
- **侧边栏、弹层菜单与模型胶囊**：提高侧边栏项（`#nav button[data-view]`、`#prefs`、`.side-gw`）与协议/时间跨度菜单（`.proto-menu .pm-item`、`.rm-item`、`.pop li`）悬停、聚焦与单选选中态样式优先级；模型选择胶囊 `.mchip` 及其自动/选中态切换为无深色描边的晶透玻璃胶囊。
