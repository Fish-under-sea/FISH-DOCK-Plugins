# Magpie 插件 1.2.1

修 1.2.0 里签到页打不开的问题，并修深色模式下插件页图标看不见。

## 修复

- **签到页「读取签到状态失败：没有声明读取 checkin:state」**：`checkin:state` 之前只登记成“调用”，没进“可读白名单”，页面的 `magpie.read` 被宿主拒掉，于是整页只显示「还没有登录的账号 / 这个页面需要 magpie 1.1 或更新版本 / 读取签到状态失败」。现在 `checkin:state` 是一等读，`/api/plugin-pages/read` 正常返回。
- **签到页数据契约**：`checkin:state` 现在返回页面真正要的 `{providers, accounts, today, credits, creditEstimate}`——厂商、已登录账号、今天每个账号的结果与实得积分、以及按额度面板反推的估计；不再返回一坨跟页面无关的旧结构。
- **插件页图标颜色**：插件页图标是 `<img>` 里的 SVG，图内用 `currentColor`，而 `<img>` 不继承主题色，深色模式下永远是黑的。现在按主题钉死：浅色黑、深色白；无图标的内联 SVG 不受影响。

## 页面

- `page-checkin` 0.2.1：账号按 key 的 `<厂商>|` 前缀归组，兼容宿主 `by` 的三种写法，不再漏号。
