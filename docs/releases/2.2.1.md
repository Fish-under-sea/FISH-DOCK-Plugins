# Magpie 网关插件 2.2.1

基于上游 magpie `v0.1.2799`（`c9824bb3`）+ 累计补丁 `fish.15`。仅更新 magpie 单插件，其他插件不变。

## 修复与增强

- **网页超链接承接（工作包 D）**：本机内嵌管理页的 HTTP(S) 外链（帮助、官网、社区、仓库、下载、更新、授权确认）改走宿主受控打开入口 `POST /api/open`，仅限回环连接，保留 URL 参数与 hash，打开失败回传错误并给出可复制地址；独立浏览器与远端网页保持原有客户端打开行为。插件页（含 NearToken 0.6.6 的普通 anchor / target=_blank）的受信任用户导航经页面桥接 `link` 消息交由宿主打开：要求真实用户激活、帧持有焦点、单次消息去重，站内路由与页内锚点不外跳，未放宽 sandbox/CSP 与调用声明。已在真实 Edge 的独立、网页、Dock 型嵌入三种模式下验证鼠标与键盘操作、参数保留与单次打开。
- **邀请资料透传（#26 宿主侧）**：授权 `user` 的 `aff_code`、`aff_count`、`aff_quota`、`aff_history_quota`、`inviter_id` 与账户标识经 `summarize` 透传到 `Account`/`View`；未知与真实 0 分离，当前与历史奖励分开保留原始单位，附 `referralSource=authorization_user` 与授权更新时间；缺邀请字段的钱包应答不覆盖已有资料；新授权缺少 `user` 时不沿用上一位账户。
- **账户生命周期隔离**：断开或换号后的在途旧钱包响应不再写回（发起前与提交时双重核对凭据与授权代次，返回 `ACCOUNT_CHANGED`）；授权完成期间断开时，晚到的授权不写回凭据、不重建账户；迟到的保存不再把更旧状态写回磁盘。
- **前台超时网页兜底（新需求）**：connect、显式 refresh、带 amount 的 topup 设 25 秒总时限并继承调用方取消；超时或服务端错误时保留原错误并在系统浏览器打开对应页面（`/sign-in`、`/wallet`、`/pricing`、`/usage-logs/`），单次操作至多打开一次，后台读取/用户取消/参数错误不弹窗，不重发有状态 POST，兜底地址不含令牌或兑换码，打开失败给可复制地址。
- **模型启停（#25）**：以实际工厂第二参数 `disabledModels` 重新验证 options.set → 宿主重启 → provider.models → 缓存 → 供应商列表链路；单选、全选恢复、重启保留、每秒限流均有回归测试。修正了旧诊断夹具误读 auth.options 的假阳性，未据此乱改宿主取值逻辑。

## 已知边界（如实说明）

- 兑换桥接（#27）尚未实现：公开前端 `POST /api/user/topup {key}` 契约已知，但设备令牌权限与桥接结果结构未确认，本版不虚构 `neartoken:redeem` 能力。
- 新 API 前缀 `/api/magpie/device/*` 待站点部署验证后再迁移；本版保留当前兼容路径，不对有状态 POST 跨前缀重试。
- 邀请资料、模型清单与超时兜底均以本地替身与真实浏览器验证，未做真实账户联调；`ACCOUNT_CHANGED` 等新错误码的页面分支由独立插件后续适配。
- Windows x64 构建；macOS/Linux 未构建。
