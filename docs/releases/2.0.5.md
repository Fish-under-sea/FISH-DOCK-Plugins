# Magpie 2.0.5

**只发 Magpie 一个包**（`magpie.fish-plugin` 2.0.5，exe `magpie v0.1.2336+fish.6`）。Clash 仍是 2.0.2，飞书与 OFM 仍是 2.0.1。

## 讯飞：这次是全量账号、每号 400

2.0.3/2.0.4 把「固定一个号 + 400」理解错了——当时做成了**只签一个账号、列表也只显示一个**，你看到的「1 个账号」就是它裁出来的。正确口径：

- **账号全量**：登了几个就列几个、签几个，`4/4` 就是四个号都签过；
- **每个号 400**：插件报了正数就用插件报的，没报按 400 记（`4 个号 = 1600`）；
- **读取侧也补**：历史记录里插件当年没报的 0，读出来时按 400 显示，不用等明天重签。

用例直接盯住「账号一个都不许裁 + 签到页列出全部 + 每号 400」这三条，防止再退回去。

## 签到页的厂商标志

- **Trae**：原来那张家图整张黑底，抠掉后浅色底是白底 + 绿线框、深色底是黑底 + 绿线框。
- **Cline / OpenCode Zen Free / Xiaomi MiMo**：原素材是 `currentColor`，`<img>` 里的 `currentColor` 永远解析成黑色，深色底上等于黑压黑。三张各配一份深色版（反白），浅深两套都清楚。
- **其余照旧用原素材**，一张没重绘。
- **22px 视觉大小拉齐**：各家原图留白不一样（讯飞的 X 只占画面一半、Kiro 那种本来就撑满），给每个厂商一个缩放系数（讯飞 1.25、MiMo 1.20、Cline / OpenCode 1.15，其余 1.00~1.05），格子一样大、图标看起来也一样大。素材文件本身没按这个改，缩放写在 `page/app.js` 的 `LOGO_SCALE` 里。
- 深色界面优先取 `<provider id>-dark.*`，没有就退回同一张。

## 内置两个插件的图标换成品牌图

`page-checkin` 与 `page-relay-probe` 在 magpie 插件页里的图标，换成 `DSH-FISH_256x256.ico` 导出的 256×256 PNG：

- `page-checkin` 原来指 `page/icon.svg`，改成 `page/icon.png`（旧 svg 已删，引用与断言一并更新）；
- `page-relay-probe` **原本没有 icon 字段**，所以插件页一直是默认方块，这次补上。

这两处走 magpie 自己的 `magpie.page.icon`，不碰 exe。

## 升级：还是「卸载 → 安装」

Magpie 的 `credentials/magpie-runtime/` 有 400 MB 运行时，宿主那条「更新前回滚点」必失败（[FISH-Dock#34](https://github.com/Fish-under-sea/FISH-Dock/issues/34)）。卸载保留 `%USERPROFILE%\.fish-dock` 下的账号、订阅与签到设置。
