# Clash 插件 1.3.1

概览页按 Clash Verge 的信息卡重排，节点页补上搜索与排序，并修掉「内核运行时订阅表单被静默禁用、点不动」的问题。内核仍是 mihomo v1.19.15，GeoIP/GeoSite 数据仍随包内置。

## 新增

- **概览八卡**：订阅、当前节点、网络设置、代理模式、网站测试、IP 信息、Clash 信息、系统信息。主卡跨行、副卡两两等高；620 单栏与 960 双栏都是两列，只换每列横向余量。
- **节点页**：顶部常驻搜索（按节点名 / 订阅名）、「按延迟」排序、「只看可用」过滤；组卡横排，切组后列表回到顶部；只有节点列表内部滚动，工具栏与搜索不再被滚走。
- **出口 IP 卡片**：经用户自己的混合代理口查询（HTTP 绝对 URI / HTTPS CONNECT），默认脱敏、点开显示，60 秒缓存；内核停止时降级提示。
- **网站测试卡片**：从主组逐层解析到叶子节点，再对该节点测 Apple / GitHub / Google / YouTube。

## 修复

- **「无法继续添加订阅」**：真实原因是两层限制叠加 —— 后端 `editable()` 拒绝在运行中改配置，页面 `locked()` 又把 `view.running` 算进禁用条件，于是内核一跑，输入框与「保存订阅」就变成 `disabled` 且没有任何说明。现在运行中在订阅区显示「先停止内核」说明与就地「停止内核」按钮，不再静默禁用。
- **字段级校验**：名称与地址校验失败改为 `aria-invalid` + 字段下方文案，不再只闪一条全局状态。
- 节点列表漏了 `.nodes` 网格容器（节点被排成单列药丸）、`.node span:last-child` 特异性压过延迟色阶（延迟一直显示为灰）。

## 后端

- `view` 增补 `rulesCount`、`uptimeMs`、`os`。
- 新增 `clash.ipInfo`、`clash.siteTest`；`runtime.proxiedGet` 只用 `http` / `net` / `tls`，64KB 上限、6 秒超时、不跟随跳转。

## 已知未做

- 概览内容在 620 / 960 下约 1.44k px 高，宿主容器更矮时整页滚动，没有做容器内滚动。
