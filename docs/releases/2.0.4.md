# Magpie 2.0.4

**只发 Magpie 一个包**（`magpie.fish-plugin` 2.0.4，exe 版本 `magpie v0.1.2336+fish.5`）。Clash 仍是 2.0.2，飞书与 OFM 仍是 2.0.1。

## 修 2.0.3 的两处没收干净

### 1. 讯飞显示「1/1 · 0 今日」——积分没补上

2.0.3 只在**新签到**那一刻把积分记 400。可当时的账号在今天**已经签过**（记录里 `Credit` 是插件当年没报的 0），所以页面读到的还是 0，看着像没生效。

`fish.5` 把同一条口径补到**读取侧**（`internal/provider/checkin_view.go`）：读今天的签到记录时，讯飞的 `Credit` 若 ≤0 就按 400 显示。历史记录、老账号、新账号一视同仁，页面上就是 400。

### 2. 讯飞图标是破图——抠图抠成了细线

2.0.3 把「科大讯飞」标志的 X 形符号抠成透明底，22px 格子里只剩几根细线，深色底上还发灰，看着就是破图。

重做成**带底色的圆角方块**，跟 ZCode / WorkBuddy 那些标一致：

| 文件 | 用途 |
| --- | --- |
| `loomy.png` | 浅色界面：白底圆角 + 深色符号 |
| `loomy-dark.png` | 深色界面：深灰底圆角 + 白色符号 |
| `loomy-plugin.png` / `loomy-plugin-dark.png` | 同上两份，给 provider id 写作 `loomy-plugin` 的版本 |

## 签到页现在支持深浅双图标

`page/logos/` 的约定扩了一条：深色界面下优先取 `<provider id>-dark.{svg,png,webp}`，没有就退回同一张普通图标。品牌标志在深色底上常常要反色（白底方块贴在深色卡片上很刺眼），有了这条就不用在「哪张都能看」上妥协。

素材与裁切范围仍记在 `page-checkin/page/logos/README.md`。

## 升级：还是「卸载 → 安装」

Magpie 的 `credentials/magpie-runtime/` 有 400 MB 运行时，宿主那条「更新前回滚点」必失败（[FISH-Dock#34](https://github.com/Fish-under-sea/FISH-Dock/issues/34)）。卸载保留 `%USERPROFILE%\.fish-dock` 下的账号、订阅与签到设置。
