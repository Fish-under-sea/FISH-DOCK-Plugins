# 2.5.0 发行说明

**Magpie** 升级到 **2.5.0**（追平上游 `yetone/magpie@v0.1.4650`，累计补丁 `v0.1.4650+fish.50` / Windows FileVersion `0.1.4650.50`，要求 FISH Dock ≥ 2.3.4），**Clash** 升级到 **2.5.0**（内置内核升级至 `mihomo v1.19.34`、新增用户级环境变量代理开关、接入 Dock 玻璃与字体「跟随」并补齐深色字体单独设置，要求 FISH Dock ≥ 2.0.0），**飞书**保持 `2.2.0` 不变。

## 本版更新（Clash 2.5.0）

- **新增显式环境变量代理（`HTTP_PROXY` / `HTTPS_PROXY` / `NO_PROXY`）**：在「网络设置」卡片新增独立开关（默认开启，便于 TUN 模式与终端 / AGY 工具链直接复用代理）。内核启动时写入 `HKCU\Environment` 并广播 `WM_SETTINGCHANGE`，自动保留已有 `NO_PROXY` 例外并去重补齐本机回环；停机、异常退出、启动自愈与 Windows 看门狗 `recover` 均同步还原 `system-proxy.json` 与 `env-proxy.json` 租约。
- **内置 `mihomo` 内核升级至 `v1.19.34`**：由 `v1.19.15` 升级至上游 `mihomo-windows-amd64-compatible-v1.19.34`（Go 1.26.11 / `with_gvisor`），通过实机配置语法与多订阅 SafePath 校验。
- **液态玻璃与字体颜色接入 Dock Hook（「跟随」）+ 深色字体单独设置**：接入新版宿主 `FishDock.theme`，液态玻璃预设与字体颜色模式均新增「跟随」选项；补齐字体颜色「深色单独设置」（`fontDark` / `fontDarkOn`）；收敛玻璃表面不随强调色染色，且不额外引入强调色选择器。

## 本版更新（Magpie 2.5.0 · `fish.50` · 基线 `v0.1.4650`）

- **上游追平至 `v0.1.4650`**：合入上游最新网关、供应商与界面改动，消解 `fish.49` 全部 8 处冲突与 `geminiServed` 命名冲突（fish 侧改为 `audioGeminiServed`），修正 `i18n.js` 缩进并重扫 `glass-surfaces.mjs --write`（165 条玻璃表面规则），导出新累计补丁 `magpie-v0.1.4650+fish.50.patch`；同步更新脚本字节预算（`appScriptBudget = 1_099_222`、`coreScriptBudget = 1_285_652`）。
- **液态玻璃与字体颜色接入 Dock Hook（「跟随」）**：适配层（`embed-proxy.mjs`、`shared/gateway-page.js`）新增 `/api/fish/dock-theme`、SSE `/api/fish/dock-theme/stream` 与 `/api/fish/glass-state` 桥接，并修复 Node 24 下 `req.once('close')` 过早断开 SSE 流的问题；Magpie 外观页液态玻璃预设与字体颜色模式均新增「跟随」并持久化 `fishGlassFollow` / `fontColorsFollow`。
- **玻璃模式下顶部服务条自动透明**：`shared/gateway-page.css` / `shared/gateway-page.js` 在 `data-dock-glass="1"` 或 `data-magpie-glass="1"` 生效时自动隐藏顶部服务栏黑色底色（不增设开关，保留 `prefers-reduced-transparency: reduce` 与 `forced-colors: active` 可读性回退）。
- **收敛字体强调色对液态玻璃的染色**：在 `fish-glass.css` 中将玻璃表面/卡片/面板/遮罩底色收敛为中性色，并移除 `.rt-groups > .rt-gedit` 的 `--accent` 底色铺染，保留开关、聚焦与文字强调色本身。
