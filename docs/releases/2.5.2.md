# 2.5.2 发行说明

**Clash** 与 **Magpie** 双插件同步升级到 **2.5.2**（注：旧标签 `v2.4.2` 已占用，本次双插件按主线递增至 `2.5.2`）：**Magpie** 追平上游 `yetone/magpie` 至 **`v0.1.4709+fish.51`**（要求 FISH Dock ≥ 2.3.4）；**Clash** 全面加固 Windows TUN 服务稳定性、托管内核副本与看门狗轻量注销，并逐项对标 Clash Verge 重构 DNS / TUN / 订阅原生分流合并与连接清理（要求 FISH Dock ≥ 2.0.0）；**飞书**保持 `2.2.0` 不变。

## 本版更新

### Magpie 2.5.2（`v0.1.4709+fish.51`）

- **追平上游 `v0.1.4709`**（相对 `v0.1.4650` 共 59 个上游 tag）：
  - 导出累计补丁 `plugins/magpie/patches/magpie-v0.1.4709+fish.51.patch`（`1,650,395` 字节），在全新上游源码树上实现 **254 文件 / 452 hunk 零冲突重放**，悬空引用闸门（`check-assets-refs.mjs`）与密钥字面量扫描全部通过；
  - 解决 `navicons.js` 与 `core_budget_test.go` 两处冲突并保留设置页「外观」图标；`glass-surfaces.mjs` 重扫 **165 条**液态玻璃表面规则（`--card=129` / `--card-2=34` / `--bg=2`），同步更新 `core_budget_test.go` 实测脚本预算（`appScriptBudget = 1_099_860`、`coreScriptBudget = 1_287_215`）；
  - 自编译产出 `magpie-windows-amd64.exe`（`v0.1.4709+fish.51` / `FileVersion=0.1.4709.51` / `ProductName=magpie fish`）。

### Clash 2.5.2（服务防断链 + 对标 Clash Verge 速度与配置重构）

- **加固 Windows TUN 服务防假断链与休眠恢复**（`plugins/clash/service/tun-service.cs` / `tun-service.exe`、`plugins/clash/tun.mjs`、`plugins/clash/service.mjs`）：
  - `tun-service.cs` 将宿主失联判定从「触发计数」改为**真实墙钟计时（15 秒宽限）**，`FileSystemWatcher` 文件事件仅执行 `Tick(false)` 不再提前推进失联计时；新增 `OnPowerEvent` 电源唤醒与时钟跳变检测，休眠恢复后自动给予 **25 秒宽限**，彻底消除休眠唤醒或短时卡顿导致的 `host is gone` 误断链；
  - `tun.mjs` 区分 `sc.exe` 真正的 `1060` 未安装与瞬态查询失败（改报 `unknown` 而非伪装 `absent`），并为 `status()` 增加 2.5 秒 TTL 缓存与并发合并；`service.mjs` 在 `view()` 判死前忽略 `unknown` 并增加 `/version` 探活与 30 秒周期租约续期；
  - `tun.mjs` 安装服务时将 `mihomo.exe` 复制为稳定托管副本 `C:\ProgramData\FishDock\clash-tun\mihomo.exe`（Users 只读 ACL）并在 `service.ini` 记录 `kernelSha256`，`runtime.mjs` 优先按 SHA-256 比对内核一致性——插件升级（只要 `mihomo` 版本不变）不再强制触发 `TUN_KERNEL_MISMATCH` 与重复 UAC 重装。
- **看门狗轻量注销与内核日志落盘**（`plugins/clash/watchdog-task.mjs`、`plugins/clash/runtime.mjs`、`plugins/clash/service/tun-service.cs`）：
  - 看门狗 `stop()` 优先调用原生轻量 `schtasks /Delete /TN <name> /F`（自动兼容中文 Windows GBK 错误输出，静默容忍任务不存在与关机/Job 销毁瞬间的 `0xC0000142` 中断），避免停机阶段拉起 `pwsh.exe` 超时；
  - 用户环境变量读取优先走 `reg.exe query HKCU\Environment`（失败回退 `pwsh`，超时放宽至 10 秒）；
  - 普通模式与 TUN 服务模式统一捕获 `mihomo` 的 `stdout` / `stderr`（脱敏 `secret` / `Bearer`），按 512 KiB 自动轮转写入 `tmp/mihomo.log`，便于排障定位。
- **逐项对标 Clash Verge 优化节点速度与订阅原生分流**（`plugins/clash/runtime.mjs`、`plugins/clash/service.mjs`、`plugins/clash/page.js`）：
  - **DNS 与连接性能**：默认 `dns.respect-rules: false`、`dns.fallback: []`（避免海外域名解析绕行代理与多路并发查询拖慢首包），新增 `profile.store-fake-ip: true`，移除硬编码 `keep-alive-idle: 15`，并将内置 `url-test` / `fallback` 调整为 `lazy: true` + `interval: 300`（防止高频并发测速触发机场限流）；
  - **TUN 默认参数**：默认栈调整为 `gvisor`，默认关闭 `strict-route`（与 Clash Verge 默认一致），并在「内核设置」页提供「严格路由 strict-route」开关；
  - **切换立即生效**：`select()` 切换节点与 `mode()` 切换模式后自动调用 `DELETE /connections` 断开旧连接（对标 Verge `auto_close_connection`），防止长连接滞留慢节点；
  - **方案 B1 单订阅原生 YAML 安全白名单合并**：新增「订阅配置策略」设置（默认「订阅原生分流（优先，对标 Clash Verge）」，可随时切回「内置分流规则」）。单条完整订阅保留原生 `proxies`、`proxy-groups`、经路径收敛（`./ruleset/<safe>-<idx>.yaml`）的 `http` `rule-providers` 与 `rules`，同时强制剥离订阅中的端口、`allow-lan`、`external-controller`、`secret`、`dns`、`tun` 与危险 `type: file` 规则集；纯节点订阅、多订阅或遇未定义锚点/缺 geo 时平滑回落内置分流；同步增强 `resolveLeaf()` 与概览路由识别以原生兼容任意订阅主组名。
