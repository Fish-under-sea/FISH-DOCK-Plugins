# Clash 2.0.7

**本次只发 Clash 一个包**（`clash.fish-plugin` 2.0.7）。Magpie 仍是 2.0.5，飞书与 OFM 仍是 2.0.1。

## 1. 顶部收成一行：页签 + 启停 + 刷新

之前是两行——第一行五个页签，第二行「启动内核 / 刷新」。现在挤在同一行，**永远不会折到第二行**：放不下就横向滚，不换行。

## 2. 内核设置变成独立页签

那个钉在每页最底下的「› 内核设置」折叠条拿掉了，改成第四个页签：mihomo 路径、混合代理端口、控制器端口、TUN 段与服务按钮全在里面。概览页不再拖着这坨输入框，翻到哪儿都少一截。

「保存内核配置」按钮吸底（`position:sticky`），滚到哪一段都能直接按到。

顺带修了 TUN 段的排版：`dock.css` 把 `legend` 设成 `float:left; width:100%`，字段集被挤出一大块空白、勾选框被推到下面。现在 legend 回到正常流，勾选框、栈、服务状态、三个按钮从上往下排。

## 3. 规则页与连接页移除

这两个页签没有实际作用，整页拿掉（连续点进去只看得到「内核运行后显示…」）。后端 `clash.details` 能力仍然在（规则与连接的读取逻辑、脱敏与条数上限都保留在 `service.mjs` 里），只是页面不再给它入口——将来想要回来，加一个页签接上就行。

## 4. 双栏彻底删掉

2.0.6 只是页面上不画切换按钮，`layout` 这层还留着（配置项、`clash.layout` 命令、后端校验）。这次连根拔：

- `service.mjs`：`defaults.layout`、`clash.json` 里的 `layout` 字段、`layout()` 命令全删；
- `backend.mjs`：命令表里不再注册 `layout`；
- 页面：不再发任何 `layout` RPC。

老的 `clash.json` 里残留的 `"layout": "double"` 会被直接忽略，不影响启动。

## 5. 节点页加「测速」

节点工具条上多了「测速」：对当前组的每个节点打一次控制器的 delay 接口（并发 6，上限 200 个节点），结果按节点名写回页面，列表里的延迟、颜色、「按延迟」排序、「只看可用」过滤立刻按新值走。

单个节点超时只把它自己标成「未测速」，不影响别的节点；内核没启动时按钮是灰的。切节点、启停内核会清空手测结果，回到内核自己上报的延迟。

## 6. 滚动：一滑就被拉回、卡住

两个原因，一起修：

- **重绘把手感打断**：内核运行时每 1.2 秒轮询重绘，整块 DOM 被换掉，滚动条跟着归零，用户看到的就是「往下一滑立刻被拉回」。现在滚动期间不重绘，停下 1.2 秒后补一次；重绘后还会把内容区与按钮行的滚动位置放回去。
- **高度不统一**：四个页签现在共用一个内滚容器（上限 560px，同时不超过面板可视高度），内容再多也只在面板内滚，不会把 Dock 面板顶长、也不会多出一层宿主滚动。

节点列表不再套第二层滚动，跟着内容区一起滚。
