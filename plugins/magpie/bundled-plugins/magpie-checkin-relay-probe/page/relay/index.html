    操作教程（点击查看）
    1. 在「目标」里填 Base URL：一般到域名层就够，例如 https://relay.example.com；有的站要带 /v1，以站点文档为准。
    2. 填 API Key：保存后只留密文，页面不回显；换 Key 直接覆盖。
    3. 主模型填你要验的那个模型名（例如 claude-sonnet-4-5）；对照模型可留空，留空时只用主模型跑三组探针。
    4. 认证方式先用 auto：自动按 x-api-key 与 bearer 各试一次；两个都失败再手动指定。API 版本只在站点要求时填（如 2023-06-01）。
    5. 点 保存 再点 开始探测：一轮约十几秒到一分钟（取决于超时设置），期间按钮会锁住，可随时 停止。
    6. 看「结论」：原生一致 / 存疑 / 疑似伪装三档，下面列出每条信号的理由；「三组探针」表里是每条的原始状态。
    7. 判定只说明「这次请求的行为像不像原生」，不等于站点一定是官方或一定是假的；换模型、换时间段各测一次更稳。
